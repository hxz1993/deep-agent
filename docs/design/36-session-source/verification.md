# 会话来源改造验证记录

2026-09-29，本地 SQLite；数据库版本保持 010。未提交、推送或升级产品版本。

## 实现

会话创建入口写入 `source_type/source_id`；渠道来源从可信账户取得，普通入口写 internal。查询只将历史 NULL 视为 internal，不推断或回写来源。Binding 继续负责路由；来源不能替代发送授权。

渠道统计以会话来源筛选，按用户提问 Event 的时间统计，Runs 只归属真实发送者；无法归属的控制台续问单列。当前资料继续使用统一资料服务及渠道适配器，旧姓名快照不用于当前搜索。页面来源标记、Inspector 和 E 方案提醒使用主表字段，标题保持原样。

## 固定数据对账

使用同一份一致性备份、相同截止时间和 Asia/Shanghai 时区。全量按既有时间窗口限制分为两个区间。副本独立修复 16 个历史渠道会话后比较。

## 限制及后续验收

群/成员列表与明细需要批量读取结构化聊天对象。此前未经确认加入的 1000 个会话 / 10000 条标题事件限制已删除。发送者账本先关联当前来源与时间范围内的实际提问 Run，再聚合，避免账号全历史聚合。概览不读取聊天对象元数据。大规模数据库性能及各客户端真实收发仍需补充部署前验收。

Test 历史修复等待用户发版后单独指示，不自动随升级执行。010 包含既有删表，恢复依赖迁移前备份和匹配代码。
