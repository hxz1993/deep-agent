## 如实保留的限制

1. 平台批量资料的旧协议在当前平台后端源码中没有路由，目标部署尚未带真实平台认证联调；遇到不可用会显示真实 User ID。当前本地账号资料与降级逻辑已验证，不依赖测试 App，不使用需要系统签名的替代接口冒充管理员认证。
2. 最新视觉评审改为只显示用户名；无资料显示真实 ID，不再显示或加载头像、邮箱。
3. 日志接口返回保留天数策略，没有实际最早 / 最晚文件时间；页面说明保留策略，不将目标查询范围冒称实际可用范围。历史会话可能没有仍在保留期内的日志。
4. 已有取消集成测试的 SQLite 内存连接存在偶发失效：中间一次全量和重复单例发现 `no such table: chat_sessions`，定向模块 16 / 16、最终独占全量通过。未修改取消语义或测试 fixture 掩盖问题。

本次没有验证真实平台账号服务升级兼容性、大规模生产数据的延迟 SLA 或跨环境权限；不将隔离测试和本地只读验收扩大解释为这些能力已经验证。
