# DeepAgent 0.14.2 复杂约束编辑验收

日期：2026-10-22。分支：`test`；基线：`v0.14.1 / 015c72e`。目标：`v0.14.2`，数据库 Head 仍为 `012`。

## 结论与边界

Console 原先因根存在 `allOf` 等节点而禁止整个字段模式。现在对有直接根 `properties` 的对象展示卡片，同时保留完整条件、组合、本地引用、内部 required 和扩展注解。卡片只维护当前根字段及根 required，不扁平化 Schema，不生成业务表单。只从分支/引用继承字段而没有直接 properties 的复杂定义，以及数组/标量，继续使用原生编辑器；裸空对象保留原卡片流程。

受同实例复杂规则关联的字段允许同名内容编辑，禁止单独改名、删除、切换根必须或新增受约束编码，并显示具体 JSON Pointer，要求在原生 Schema 中同步修改。保护在草稿 mutation 层执行，禁用控件不是唯一防线。改名检查新旧两个名字，新增检查确认后的最终名字；不会因自动建议名受约束而无法输入其他合法名称。子对象同名字段、未使用的 defs 和说明性注解不误判为根引用；无法证明安全的同实例未知规则保守保护。引用只解析展示类型/字段数，原始引用不展开写回。

同名修改 type 不意味着覆盖其他条件；约束继续取交集。平台合法 Schema 校验不保证业务规则可满足，BOM 批准、引用、哈希、业务保存继续由客户端核验。

## 真实定义的语义保持

对 AlphaPG 实际完整定义及浏览器编辑保存后的定义，分别执行现有服务端隔离子进程 `validate_output`，逐项比较接受/拒绝及错误约束列表，9/9 一致：

| 合成输出 | 原定义 | 编辑保存后 |
| --- | --- | --- |
| 首轮完整快照 | 接受 | 接受 |
| 后续稀疏补丁 | 接受 | 接受 |
| ready 且行决策已明确 | 接受 | 接受 |
| 首轮 snapshot 为 null | 拒绝 type | 拒绝 type |
| 首轮 revision 为 2 | 拒绝 const | 拒绝 const |
| 后续轮仍返回完整 snapshot | 拒绝 type | 拒绝 type |
| 后续轮 base_hash 为空 | 拒绝 pattern | 拒绝 pattern |
| ready 时行仍 pending | 拒绝 anyOf | 拒绝 anyOf |
| 新增未知根键 | 拒绝 additionalProperties | 拒绝 additionalProperties |

本地保留用户要求的 **BOM 复杂约束输出验证**（`833509d2-3c63-448e-a23d-29bcad4c0d1e`），结果名称 `bom_turn_v3`、16 个顶层字段。浏览器试改后已恢复成源定义并通过 API 全对象相等核验。此 Agent 没有默认模型、工具和 Skill，仅用于查看与编辑，不复制线上提示词或执行权限；如要真实业务运行，由用户另行配置。
