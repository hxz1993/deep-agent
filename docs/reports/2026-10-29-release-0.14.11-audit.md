## 变更与审计修复

- Skill 维护改为顶部筛选、紧凑表格及第二页详情。筛选依次为全部 Skill、未被引用、分割线和已有 Skill 引用的 Agent；按 Agent ID 配对，共享 Skill 不重复展示。自定义稳定置前、内置置后，名称旁仅保留内置标签。
- 引用列显示一个机器人名称和 +N 非模态浮层；状态独立展示真实运行文件状态，不能解释为业务校验成功。搜索名称、编码和描述；返回恢复筛选、滚动与焦点。首屏不自动读取详情。
- 详情复用既有编辑、上传替换、下载、重载、删除门禁、包格式及资源预览；标题左侧返回，最大1080px，左侧320px，预览使用剩余空间并撑满高度。1000px以下纵向排列，表格沿用窄屏隐藏次要列与横向滚动。
- 新增管理员只读 `GET /api/v1/skills/references/agents`，一次查询只投影现有 Agent.id/name/skills，不加载提示词、模型或账号资料，不写入关联副本。原 `/skills` 和所有既有详情／写接口保持不变。
- 列表、引用、详情及文件读取使用取消和请求代次校验，拒绝切页或切换后的迟到响应；引用查询与 Skill 列表并行，失败保持明确错误。写操作不因切页重试。
- 共享下拉仅在显式标记时增加图标和分割线；已删除 Skill 旧主从布局专属规则，相邻管理页保持原布局。入口、动态配置脚本及共享控件缓存引用统一更新。

审计中复现并修复：

1. 未发布的 `/skills/agent-references` 路径遮蔽同编码 Skill 详情：改用上述多段路径，增加真实安装 `agent-references`、`references` 后读取详情的集成用例。

4. 引用刷新失败时下拉仍显示原 Agent、表格却显示全部：同步回退口径，读取期间禁用依赖引用的筛选，成功后恢复有效选择。
