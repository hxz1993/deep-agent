# Console、安装和备份

聊天和 Agent 编辑沿用模型下拉，按 Provider 分组。模型列表单独滚动，Thinking 固定在菜单底部。选模型后保留下拉菜单，可继续从侧边菜单选档。没有可选档位时只显示「默认」。模型弹框在同一行展示和编辑原生档位，无声明时提示使用供应商默认。目录保留原列，另加原生档位只读列。会话概览只在原模型名后拼接 ` · 高` 或 ` · 默认`，旧轮只显示模型。

聊天中的手动选择在当前 Console 页面按模型保留。多轮发送、切换会话或切回原模型时复用仍可选的档位。刷新页面后按 Agent 与供应商默认规则重新解析。

目录在线刷新保存目录快照。模型弹框按供应商及原生模型编码匹配目录，也识别旧配置中的带前缀标识。能力刷新保留手工档位，显式恢复目录档位只替换档位。复制保留仍适用的设置。

Agent ZIP 格式沿用 v1。仅非默认配置带档位、模型编码和协议。新版回装时重新验证目标模型，不能使用时在预检说明回到默认。旧包仍可新装和覆盖。配置备份按实际 011–014 Revision 投影并同 Revision 恢复。
