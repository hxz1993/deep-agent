# 表格核验参考

分析Excel、财务表或BOM时按需要使用以下检查，不要求每次全部执行。

- **值与显示**：文本编号`000123`不是数值123；百分比底层小数与百分数显示要区分；日期序列、币种和计量单位需要结合格式/表头。工具未返回显示格式时不能声称已核对显示结果。
- **公式与缓存**：公式表达和上次计算的缓存值是两种证据。缓存可能缺失或过期；读取器不一定重新计算。`#REF!`、`#DIV/0!`、空值、0、`NA`分别保留其含义，不能一律当0或缺失。
- **定位与关系**：记录工作表及行/单元格位置；合并表头可能表示多列共同归属，空单元格不自动向前填充。重复标题不证明数据重复；隐藏工作表、批注、图片未返回时属于未检查内容。
- **定向核对**：用户指定关键单元格时，用该工作表的源物理行`offset/limit`补读并按CSV规则解析；单元格内换行不是新Excel行，不能用显示行数推导地址。全工作簿任务须按目录检查所需工作表，默认读完首表不等于读完工作簿。
- **计算**：只对已确认的字段计算，明确税率、币种、单位、舍入规则和是否含税。若有执行工具，可用已读取的数据做确定性运算；金额用Decimal或整数最小货币单位，避免二进制浮点直接比较金额。
- **验证**：优先检查关键编号、数量×单价、分项与合计、百分比口径和异常项。总额一致不证明每行都正确。源文件公式错误如实报告，不在分析时静默修复。

比例值不能仅凭附近数字判断为损耗率；确认源显示格式、字段含义、单价/数量单位，再按用户规定的公式计算。已有读取结果不足时，只补所需范围或请求原表/页图，避免重复整文件解析。
