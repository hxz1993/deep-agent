## 当前方案与实现边界

诊断中心作为一级目录，下面提供「日志」「会话」两个独立入口。

- **日志沿用 L4 的信息组织，与 Console 统一视觉**：桌面 34px 行高、13px 内容，顶栏筛选单行右对齐；移除状态圆点、表格网格和逐行分割线，
  内容行右侧只显示 Session ID。右侧详情按左标签、右值分组，移除重复 JSON 和大号关联按钮；Run ID只保留值。
- **会话概览参考 S1，列表参考 S2**：同页切换并共享 Agent、时间、平台用户、来源筛选。
  概览保留四项指标、提问趋势、Agent 分布、最近提问、最近异常和活跃账号；整体白底，图表、表格保留必要边界，筛选不套外框。最近提问38px单行，列表50px双行；次行展示“Session ID＋复制 · 最近问题”。趋势横坐标随容器重算，文字和圆点不拉伸。
- **详情参考 S3，复用对话测试**：共用正文、工具、轨迹和信息栏的展示层，独立诊断状态，完整只读页面。
  不复制整页执行控制器，不提供发送、重试、停止、审批、改名、删除或手动压缩。
- **账号口径**：所有普通 / 渠道会话统一按平台 User ID 汇总；不解析或统计企微实际发送人。
  仅显示用户名，不显示头像或邮箱；账号服务不可用降级显示真实 ID，不依赖测试 App，也不新增全企业姓名检索。

生产数据来自现有会话 / 事件和当前部署实例的安全诊断日志，不接原型假数据；不增加统计表、数据库字段、迁移或新事件。
不增加导出、实时订阅、渠道专项统计、成功率 / 满意度、自动分类、跨环境日志聚合或跨用户文件代理。

## 联动是独立交付项

概览指标、日期、Agent、平台账号可下钻到带条件的会话列表；最近提问「查看全部」直接进列表。
具体问题 / 异常进入对应会话，定位消息 / 轨迹事件。列表进入详情后返回恢复原筛选、分页和滚动。
日志内容行打开右侧详情，Session ID 打开会话；Run ID不再参与筛选、复制或跳转。会话详情不增加反向跳日志操作。
跨页查询携带完整 ID 和真实时间范围，清除无关残留条件，浏览器后退保留来源状态。

完整联动矩阵、统计口径、只读与权限约束见[会话指南](../../guides/diagnostic-sessions.md)；
日志保留期、部分扫描、游标和文件边界见[日志指南](../../guides/diagnostic-logs.md)。
会话查询与日志查询不是同一个事实源，不能拿某天日志缺失推断会话异常或没有用户提问。
