## 实现边界

- 仅将 text/thinking 展示按 75 ms 合并，原始数据即时进入各自缓冲。工具、思考分段、结构化输出、完成、错误、停止均先刷新；离开页面／销毁则取消待展示任务。
- 流式期间保留 Markdown、表格及代码结构，暂停语法高亮，终态恢复完整高亮。既有净化、复制、代码折叠和下载规则保留。
- 折叠工具的参数和原始结果按需解析；文件／图片入口即时可用，人审不延迟。重复更新展开时展示最新值，历史刷新先挂载已展开详情，再恢复代码状态。
- 隐藏轨迹接收并校准全部事实，但不排渲染。打开后按稳定事件 ID 复用行；详情只在相关事件／页签变化时更新，保留选择、焦点及滚动。
- 图标仅处理所属新增子树；实际 bundled Lucide 不支持 root 参数，因此使用其公开 SVG factory，避免传无效参数后仍全局扫描。
- reset／真实跨会话切换取消排队帧并清除旧行、详情缓存；同会话普通隐藏保留可复用行。
- History、轮询兜底、SSE、事件持久化、权限、模型和工具执行不改；没有新增生产 HTTP 路由、字段、依赖或迁移。依赖变更：无；数据库保持 013。

## 同数据前后对照

客户附件只含 4 个完整事件及第 5 个截断事件，无法恢复完整会话或实际 SSE 时序。本轮使用完全脱敏、确定性的代表负载，不包含客户原文；不把模拟结果称为客户环境验收。

固定数据：2 轮、17 次模型响应、31 次工具调用，61,850 字符思考、136,111 字符工具正文、2,567 字符答案；生成对应 51 个历史事件。工具正文含 JSON／文本，另有 JSON、TXT、PNG 下载产物。切为 8,130 个固定增量，以每批 32 个、间隔 8 ms 回放。

优化前源码保存在私有 TMP 目录；前后使用同一浏览器、视口及 fixture，实际加载产品 presenter、trajectory、Markdown、DOMPurify 和高亮模块。固定数据 SHA256：`5027112f88bb023fffa946c15473ac3fb280f71a36830627ad026e5b429d9849`。

下表是对话视图（隐藏轨迹）各 3 次的中位数；解析次数与节点数在展开详情前记录，随后展开全部结果并逐项校验完整内容。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| Markdown 重绘 | 325 | 7 |
| 折叠工具 JSON 渲染 | 47 | 0 |
| 全局图标扫描 | 362 | 0 |
| 隐藏轨迹 DOM mutation | 247 | 0 |
| 回放结束时 DOM 节点 | 4535 | 1226 |
| 大于 50 ms 的长任务 | 4 | 0 |
| 最长帧间隔（ms） | 100.2 | 17.7 |
| 总回放时间（含固定调度等待） | 5.72 秒 | 4.38 秒 |

可见轨迹及反复切换各跑一次：均保留 31 个工具、完整思考、正文及来源；当前可见轨迹列表 mutation 71 次，切换模式 67 次，未出现大于 50 ms 的长任务。这是本机固定回放结果，不代表模型或客户任务本身加速。

堆内存边界：浏览器 performance.memory 只是采样，不是隔离进程的可靠峰值。优化后的部分采样高于基线；当前 Tabbit 的 CDP 不提供 HeapProfiler.collectGarbage，未做强制 GC／三次 Heap Snapshot。不能据此判断真实泄漏，也不能宣称堆峰值下降或客户 OOM 已修复。本轮可确认的是重复解析、DOM 重建和主线程长任务减少。

## 回归结果

- Console 全量 **1085 项通过**；停止／History／Live／文件下载相关后端 HTTP 集成 **50 项通过**。没有运行无关模型全量。
- 同数据浏览器回放：隐藏 3 次、可见 1 次、切换 1 次，优化前后共 10 次；每次最终文本、全部思考、31 个调用 ID 的顺序、展开后完整 JSON／文本、轨迹调用数均一致。
- 产品 Console 完整页面使用隔离回放服务器：配置／目录只读访问本地 8000；聊天、停止、历史和下载由脱敏协议夹具响应，从未向 8000 转发聊天或写操作，也未创建验收 Agent／会话。
- 完整流式期间切换对话／轨迹，结束仍有 31 次调用和 61,850 字符思考；无遗留图标占位。
- 点击真实停止按钮，收到 cancelled 后保留 15,361 字符思考和前 4 次调用，均与输入前缀／顺序一致。
- 网络在流中途关闭且没有终态，真实 chat.js 从 History 恢复；31 个唯一工具、完整思考与答案恢复，无重复调用项。
- 完整历史重新渲染与停止后恢复均通过；真实 8000 的原 UTC 验收会话刷新后仍可读，四个修改模块均加载 render-perf2 静态版本。
- JSON、TXT、PNG 从真实 Console 下载链接取回，HTTP 200、MIME 与 SHA256 校验通过；后端集成继续覆盖文件身份与授权。
- 补齐已展开工具在历史更新后的懒加载／代码状态恢复测试；覆盖错误、停止、取消待刷新任务、HITL、只读历史、原位持久化替换和会话切换清理。

## 本地复现与交付

实际使用页面：`http://127.0.0.1:8000/console/#/workspace`，刷新即可加载增量。原有用户配置、会话和附件保留。

需要重跑固定回放时，在仓库根执行：

```bash
python3 scripts/console_performance_server.py --port 8046
```

打开 `http://127.0.0.1:8046/`；默认加载当前源码，只执行脱敏展示夹具，不调用模型或写数据库。`source=baseline` 需另给 `--baseline-root` 指向包含 console/ 的私有快照；`--fixture-json` 仅用于隔离完整 Console 协议验收。服务只绑定 127.0.0.1，结束用 Ctrl+C 关闭。

原始计时 JSON、协议夹具及优化前快照留在忽略目录 `docs/local-artifacts/TMP to delete-console-render-perf-20261105/`，方便复查和后续删除。测试中自建页面和回放进程在收尾清理；8000／8010 保留。版本继续 0.15.9，工作区待用户确认。
