## 交互约定

- 第一页先用小尺寸“新建 / 覆盖”切换；选择覆盖后再选择目标。安装来源称“预制安装包”。
- 第二页用分组列表，展示具体内容、处理方式、共享影响和缺失。内容过长滚动，不分页。仅真实需要确认的共享影响显示一次确认。
- 第三页名称和模型左右并排，每项标签与控件同行。安装后保留当前页和配置信息，在下方展示逐项反馈，不新增步骤或结果页。
- 完成后底部是“查看 Agent 配置”文字入口与“确定”主按钮。
- 视觉沿用 Console 小字号、小图标、白色背景、轻边框；状态文字为主，收敛色块。
