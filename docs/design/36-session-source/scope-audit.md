## 确认为已授权的改动

- 010 两个可空来源字段和开发期缺列补齐；NULL读取internal；新入口明确写入；不自动修历史来源。
- 以主表来源筛选 Events 提问/用量，以可信 Runs 归属真实发送者；无发送者部分单列。
- 保留平台用户、Agent、模型统计维度；不按 Agent 当前绑定推断会话来源。
- 来源校验与发送授权分开；Binding路由、账户/所有者与可信Run检查继续保留。
- 最终E提醒、Inspector来源/详情、列表提问数和时间排列、Provider分组模型选择器均有明确请求。
- 本地历史修复脚本在项目外；未将修复混入迁移或查询。
