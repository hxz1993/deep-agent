请求头配置

逐行配置自定义 HTTP 请求头，会合并到聊天页与管理后台发出的所有 API 请求中。 配置仅保存在本机浏览器 localStorage，不会上传到服务器。

名称 值

说明
  • 空行在保存时会被忽略。
  • Cookie 无法通过 JavaScript 直接设置请求头（浏览器安全限制）。保存后，若后端地址与当前页面同源，会写入 document.cookie 并由浏览器自动携带；跨域后端地址无法从前端注入 Cookie。
  • 单次请求自带的头（如 Content-Type）会覆盖此处同名字段。
  • 聊天流式接口会额外带上 Accept: text/event-stream。
