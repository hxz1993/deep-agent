# BPP 销售预算审批回填

按钮提交一次送审上下文。按指定表单、组织、年度、期间和版本定位本次预算。即使送审入口是费用表，也要在当前应用核实销售模型与 SP 目标的绑定。附件须取得正文才能引用，只有文件名时按材料目录处理。

1. 分别核对事业部和大区的预算销售额与同口径 SP 目标，列出差额（预算减 SP）及相对目标的偏差率。组织维和区域维各自核对，避免交叉重复汇总。
2. 计算事业部占集团、大区占所属事业部或集团的销售额比例，写明所用分母。比较本次预算相对上年同期实际的增幅与上一年实际同比增幅，列出相差的百分点。占比变化也用百分点表示。
3. 行业比较使用有来源、同产品、同地域、同期间的可比销售增速或结构指标。注明金额与销量口径，单列个别同行样本。内部销售结构只用于解释预算分布。
4. 一次完成核对。数据不足、基数为零或口径不一致时，将受影响的结论、缺少的材料和建议核实事项写进意见，继续交付本轮已核实的内容。最终判断由审批人作出。

## 渲染与返回

使用 `execute_skill_script`，指定 `skill_code="sany-demo-workflows"`、`script_path="scripts/render_bpp_opinion.py"`、`resource_paths=["assets/bpp-sales-opinion.html"]`。把本次结论放在工具的 `inputs` 对象中，各字段使用纯文本。下表是字段说明。

| 字段 | 要填写的内容 |
| --- | --- |
| `scope`、`summary` | 数据年度、期间、组织、版本、币种及审核范围；最值得审批人关注的结论。 |
| `shares`、`comparisons` | 事业部及大区的销售占比和分母；与历史增幅、行业基准的差异或具体缺口。 |
| `division_strategy`、`region_strategy` | 分别说明事业部、大区的预算与 SP 目标一致性，注明重点偏差。 |
| `metrics` | 非空数组。每项是对象，`metric` 为指标和范围，`budget` 为预算值与单位，`benchmark` 为比较基准，`difference` 为差异、依据或缺口。 |
| `checks` | 非空数组。每项含 `finding`、`verify`，分别填写核实事项与可执行的核实动作。 |
| `gaps` | 非空字符串数组，列出待补资料；材料齐备时说明已覆盖的范围。 |
| `sources` | 非空字符串数组，列出实际使用的来源编号、表单与坐标或资料与页码；取证受阻时如实说明已取得与缺失的依据。 |

脚本用包内模板渲染页面，返回 `result.html`。将该值完整、原样作为本轮最终回答正文，保留样式与栏目属性。按钮读取正文回填 BPP。此模式无需追问、Markdown 围栏、附件发布或下载中心。渲染失败时返回明确错误，供按钮停止发起并提示原因。
