# DeepAgent 0.14.1 Console 验收

日期：2026-10-22（Asia/Shanghai）。开发与发布分支：`test`。比较基线：`v0.14.0` / `575c6851d8cb8a63e482dbc594770c04c0b08a11`。

## 本版范围

- Agent 卡片与列表采用 Username 在上、较小时间在下的布局，保留完整账号悬停信息和操作按钮空间。
- 输出配置文案统一为“结果名称”和“说明”。结果名称仍遵循原英文标识约束，不改变 JSON 的 `output_config.name` 或工具协议。
- 两处 Schema 复用 MCP Header 的圆角高亮编辑器，原文不被高亮改写，输入层与高亮层字形一致且同步滚动。
- 结构详情“确定／取消”仅处理弹框草稿，页头保存才写 API；取消、关闭、Esc 不写入结构。无效详情在弹框内保留并报错，原生完整 Schema 的无效文本继续阻止页头保存。
- 结果名称缺失在名称框旁提示；从其他资源页签保存时，先切至输出页签再定位名称框。
- 说明与完整 Schema 向下撑满，底边对齐；空结构提供弱色虚线占位和可用的“添加结构”文字入口。

## 依赖变更（运维）

相对 v0.14.0 无依赖变更：运行、开发与沙箱 requirements、内部 wheel 及第三方 vendor 均未调整；新增 JSON 高亮共用模块为仓库自身代码，不引入第三方编辑器。无需因本补丁新增基础镜像依赖，此结论不表示已经验证线上镜像清单。

没有环境变量、生产 DDL 或迁移变更，数据库 Head 仍为012。升级要求继续沿用0.14.0数据库与源码配套约束。本次不部署 Cloud，不修改客户端、线上 Agent、提示词或 Skill。
