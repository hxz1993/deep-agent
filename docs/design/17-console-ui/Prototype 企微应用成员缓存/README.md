# 企微应用成员缓存 · HTML 交互原型

本原型仅用于确认配置页的布局和操作，所有数据均为示例，不连接服务或修改真实配置。打开 index.html 即可预览。

## 布局

- 应用列表收窄到 180px，详情获得更多宽度。
- 基础信息与关联渠道左右分栏，分割线两端留白；每个渠道添加图标。
- 成员缓存标题与重置操作之间展示总数和待更新数，下方紧凑展示最早创建、最早同步时间。
- 表格列为姓名、企微 User ID、缓存状态、最近同步、有效期至、详情。Open User ID、首次缓存和最近错误放进详情，避免占用主表宽度。

## 可体验交互

姓名 / User ID / Open User ID 搜索；有效 / 待更新筛选；同步时间筛选；同步时间排序；10 / 20 条分页；空结果；详情与复制完整 ID；重置缓存确认。

“待更新”指资料尚未同步或有效期已过，不代表成员无效或已删除。重置仅标记过期并保留身份信息，随后收到消息时按需更新，与现有缓存行为一致。

## 实施状态

本目录保留最初交互原型供设计追溯。正式页面已在 v0.10.12 实现，并按后续反馈移除关联渠道、成员详情弹框和操作列，全部缓存字段直接展示于表格，时间使用短格式；以正式 Console 和使用指南为准。

## 原型阶段的边界

制作原型时后端只有缓存统计与失效操作，列表、搜索和分页需要后续补充接口。字段已对照 WecomUserProfile 模型，不添加模型没有的邮箱、部门字段。原型本身不调用正式配置接口。

图标取自项目本地 Lucide v0.468.0（ISC），保持现有 Console 线性图标风格。
