3. 日志接口返回保留天数策略，没有实际最早 / 最晚文件时间；页面说明保留策略，不将目标查询范围冒称实际可用范围。历史会话可能没有仍在保留期内的日志。
4. 已有取消集成测试的 SQLite 内存连接存在偶发失效：中间一次全量和重复单例发现 `no such table: chat_sessions`，定向模块 16 / 16、最终独占全量通过。未修改取消语义或测试 fixture 掩盖问题。
