# 请求装配、历史与工具续跑

`/api/v1/chat` 和 `/api/v1/chat/stream` 接收 `reasoning_effort` 字符串。缺省或 null 继承实际模型上仍有效的 Agent 档位，`default` 明确跳过 Agent 档位，其他值必须是本接入支持的原生枚举。非法值在入场前返回 422。

档位进入本次 Runner 的 ModelSettings，供工具循环、PTC 及结构化纠错复用。以各接入的 SDK 请求形状发送，默认时保留原 SDK 行为。思考摘要、供应商内部用量和输出 Token 上限有各自的语义。

事件只写一个轻量字段，例如 `metadata.reasoning_effort = "high"`。原用户事件既是历史展示来源，也供 UI 工具续跑读取。续跑从既有工具调用和响应记录确定原模型与供应商。原档位或原模型不可用，或模型配置已切到另一个供应商时，提示重新发起。旧事件缺字段时使用原历史读取方式，旧 Pending 沿用原默认请求。History 投影只暴露可选字符串。
