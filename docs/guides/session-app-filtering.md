# 本人会话列表的应用筛选

普通会话列表始终限定当前可信用户。App 是查询范围，不替代平台网关鉴权或会话所有者校验；跨 App 不额外要求企业管理员。详情、继续聊天和管理员诊断的访问规则不变。

## 列表接口

`GET /api/v1/sessions` 在既有分页、Agent、关键词、时间、来源及消息筛选之外增加：

| 参数 | 范围 |
| --- | --- |
| 不传，或 `app_scope=auto` | 有效 App Header 对应应用；没有 App 时为本人所有应用 |
| `app_scope=all` | 本人所有应用 |
| `app_scope=all&app_id=budget001` | 本人在指定应用的会话 |
| `app_scope=unassigned` | App 为 NULL 或空字符串的本人会话 |

`app_id` 仅能与 `app_scope=all` 同传，其他组合返回 422。有效 Header 按聊天已有规则校验，Console 的 `X-Deep-Agent-App` 覆盖规则也适用；格式错误不会静默变成跨应用查询。

既有业务客户端无需改动请求即可默认按当前 Header App 查询。Console 显式使用 `all`，应用筛选不修改调试 App、不切换当前打开的会话。

## 统计目录

`GET /api/v1/sessions/filter-options?agent_id=…` 返回：

```json
{
  "agents": [{"agent_id": "agent-id", "session_count": 3}],
  "apps": [{"app_id": "budget001", "app_name": "年度预算", "session_count": 2}],
  "unassigned_count": 1,
  "total": 3
}
```

`agents` 是本人各 Agent 跨应用的数量，前端沿用现有 Agent 目录顺序，未出现在统计中的 Agent 数量为 0。`apps`、`unassigned_count` 和 `total` 是当前 Agent 的完整数量，与已加载页数、关键词和当前应用筛选无关。空会话沿用列表原有口径。应用按最近会话时间倒序，编码稳定排序；NULL 和空字符串合并为未关联。

统计只查询会话主表与现有 Agent 目录，两次数据库聚合，不加载历史事件、不写统计副本。加载失败显示重试，不能用零数量代替错误。

## 名称与 Console

列表及会话详情的 `SessionInfo` 增加可空 `app_name`、`space_name`。`/request-context` 同样返回这两个字段。

名称来自当前环境 System 的只读 `POST /space-app-list`（JSON 空数组请求体），使用当前可信用户及现有平台凭据，不从会话记录取得身份。一次目录查询批量解析应用和空间，中文名称只用于展示，不写回会话或事件。服务发现及显式网关路径沿用平台客户端规则。

名称缓存按环境、用户、鉴权摘要和语言隔离，5 分钟、最多 256 份，合并并发请求；包含服务发现的总查询预算为 2 秒。上游失败按相同身份退避 10 秒，避免每次筛选重复等待；恢复后重新读取。无登录凭据、不可见、已删除或上游失败时返回空名称，数据库查询失败仍正常报错。

工作台的 Agent、应用选项显示本人会话数。应用选项包含全部应用、未关联应用和已有会话中的应用，名称旁保留编码，固定入口与应用列表间保留分割线。下拉顶部可按名称或编码即时搜索，不重复请求接口；搜索时保留两个固定入口，关闭后清空关键词。仅选择选项才改变会话列表，输入关键词不改变当前会话或调试范围。手动刷新、首次发送、删除及切换 Agent 后刷新统计；切换 Agent 回到全部应用。

右侧保留 `App / Space` 标题，名称与编码分两行，编码可复制。历史会话使用创建时记录的编码，名称取当前可见目录；新对话使用当前有效调试范围。缺少名称显示“名称未获取”，未关联显示“未关联应用／未关联空间”，编码为 `—`。

右上角调试入口与原浮层不变，已配置时蓝色显示应用名称，名称不可用时退回编码，悬停保留编码；未配置时灰色显示“不分应用”。

本功能随 0.15.5 发布，数据库保持 013，依赖不变，不回填历史范围。
