# v0.13.8 发布审计与验收

日期：2026-10-19（Asia/Shanghai）。仓库 `deep-agent`，分支 `test`，基线 `aad235d`（v0.13.7）。覆盖上次提交以来全部改动；不重写既有 tag。

## 改动范围

- 诊断地址仅保留页面、会话及事件/Run定位；筛选保留在当前页面内存，历史记录仅含导航 key 和干净来源路径，不保存绝对时间或账号条件。旧相对时间地址清除冻结范围；浏览器刷新重新建立默认最近7天。本次分页、下钻及返回仍保持原查询范围与页面快照。
- 会话6条、用量4条、日志1条、渠道3条，共14条原路径 POST JSON 查询；GET仍兼容。CSV与日志导出复用统一传输。无筛选状态、账户、History保持GET；用户输入/分页/时间位于Body。管理员、可信身份、预算、no-store和只读预览边界不变。
- 内容写入失败记录类型、阶段、SDK钩子、版本、数据库方言/错误码、包内代码位置、消息/Part数量及不可变冲突字段。字段固定白名单，不记录业务正文、参数值、SQL、绝对路径、异常原文或凭据。不放宽不可变事件比较，不改历史或事务结果，不改模型配置/依赖。

- 控制台长代码预览超过15行默认折叠（Markdown围栏及共用JSON代码预览），短代码展开；正文不截断，复制完整，手动展开与换行选择在局部重渲染时保留。

## 审计修复

| 发现 | 处理 |
| --- | --- |
| 相同干净URL已无法区分不同筛选 | 使用导航key及内存payload判定，条件直接比较；保留同路由下钻、前进/后退及滚动快照 |
| 离开诊断后的空快照会覆盖已保存视图；被未保存配置编辑器拒绝的跳转可能残留payload | 无效快照不覆盖，拒绝跳转清理pending条件；新增行为回归 |
| 用量CSV原先绕过统一查询传输 | 导出复用diagnosticRequestOptions，Body与查询范围一致 |
| 后台drain失败可能归到前一条事件的Run | 在实际处理ev的异常边界记录，外层保留原失败回执与清理；新增跨Run归因和诊断失败隔离回归 |
| 调用位置收集无明确上限 | 全异常链最多256帧，仅保留最后两处包内位置 |
| 静态依赖引用多版本可能加载重复模块 | 入口及受影响依赖统一20261019-release0138；动态import保留模板变量并升级其常量，发布检查修正缓存替换引入的模板字符串问题 |
| 可选Markdown状态hook在独立History回归环境访问不存在window | 使用globalThis可选hook，保留无Markdown环境下的旧History交互回归 |
