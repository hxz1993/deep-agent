# DeepAgent 0.15.14 发布审计

基线：`test / 03578bdf`（0.15.13，Monty 1.5.0）。本轮提交此前本地完成的 PTC 源码定位、Provider 摘要／协议／用量修复，以及预算报告流水线研究资料；后者仍是课题，不是产品功能。

## 审计与验证

- PTC 使用官方暂停点位置，记录指向原始工具代码的有界引用，不重复落库源码。甘特图、授权与执行限额保持；旧历史继续回退原定位。
- GPT 订阅请求摘要但不设置 effort；OpenAI／Compatible 仅通过显式模型协议标记切换 Responses。保留其他 Provider、Chat 兼容配置、原生结构化输出与视频映射。
- StepFun 独立适配累计用量，重复和缺失用量帧不放大统计；历史用量不改写。
- 沿用已完成的相关后端 PTC 97 项、Provider 110 项、开发资料 9 项和 Console 全量 1,162 项通过结果，各组有交集，不相加为唯一用例总数。真实模型完成两段 PTC／三次 Python 计算，以及 15 次 Provider 调用；细则见对应验收记录。
- 本次收尾补开发资料／发行打包定向测试 10 项通过，静态语法、ZIP 可重复构建、敏感模式与差异检查通过，不再执行完整后端套件。
- 测试约定改为日常及发布按影响面验证，未变化的源码复用已有结果。全量保留手动入口；脚本默认值与保守选测机制不变，没有为此重做测试框架。
