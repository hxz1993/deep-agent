## 坐标抽样与必须保留的边界

已知小样的原图尺寸1224×1584，文字绘制于x=144、y=105与185。

- Paddle返回相同页面尺寸，但识别框约为`[60,28,558,77]`和`[57,104,497,152]`，其`use_doc_unwarping=true`。这些框属于展平后的图像，直接缩放叠到原PDF会错位。工具正确返回`paddle_processed_page_pixels`及`original_page_mapping=unavailable`，不能自动承诺原PDF高亮。
- GLM返回2040×2640、框`[232,177,1062,393]`；缩放至原图约为`[139.2,106.2,637.2,235.8]`，与两行文字区域相符。但单一小样不足以证明所有裁剪、旋转或重排场景；仍返回`original_page_mapping=unverified`。
- 六份历史Paddle结果均明确启用展平，192页全部报告原PDF映射不可用。GLM坐标具备页面尺寸和有效边界，但原PDF映射仍未认证。`location_status=available`仅表示供应商坐标自身可用，不能替代原PDF映射状态。
