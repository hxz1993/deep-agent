## 答案来源与样本

六份 PDF 共192页，另两份 DOCX；原件Hash、大小、物理页数保存在受保护清单。旧三份合同已有原图事实和表格金标准；新增北京／德思勤／国金先核对原图73项事实，覆盖租期、租金、付款、税率、面积和源文留白。图片选北京阶梯租金正文及明日费用表原件页。MinerU Office 另使用真正生成的 PPTX/XLSX 答案明确样例。

## 产物与复现

`run_adapters.py`运行生产协议；`run_paging.py`核验Token和逐字符续读；`snapshot_lease_contract_prompts.mjs`只读固化Demo提示词/Schema；`run_mapping.py`验证模型主动读取及字段输出（`--paired`联合读取）；`audit_mapping.py`核对选定原图事实；`audit_image_table.py`按原图金标准检查费用表行列；`audit_model_reads.py`从真实工具返回轨迹逐字符验证实际读全；`replay_mineru_artifacts.py`仅离线重放历史原生ZIP并核验源Hash。
