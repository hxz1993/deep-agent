# DeepAgent 0.14.3 允许文本输出验收

> 2026-10-22；分支 test；发布前基线 v0.14.2 / 88a12a1。本文记录最终候选验收，功能门禁已通过；最终提交SHA及远端发布回读记录在本次交付消息，并以v0.14.3解析到的提交为准。未执行项不计通过。

## 交付行为

结构化输出开启后新增“允许文本输出”二级选项，默认false。关闭总开关保留此值与Schema草稿；字段“必须”只维护JSON required。三种output_type分别为str+Deferred、ToolOutput+Deferred、str+ToolOutput+Deferred。UI最终调整为右栏上方“允许文本输出”及问号，下面“结构设置”标题与查看JSON／添加结构／检查定义三个操作，默认卡片视图。现有复杂Schema完整保留，紧凑卡片、第二行小字、填满高度、字段内部滚动及可编辑“必须”随本次发布。

新增agent_output_configs.allow_text_output列，013→012，应用和数据库非空默认false；现有Agent继续严格JSON。新字段与定义／开关／可信更新人／时间同事务保存。PATCH省略保持，null及非boolean422。

文本按真实完成分支识别，不按Python str猜测；结构化字符串、null、false均保留原生JSON及output_info。文本正常结束没有成功output事实和output_info。JSON仍完整Schema校验、真实调用／ack及接受持久化，重试有界。Turn冻结策略、Schema及预算，旧快照缺省false，恢复不被当前配置覆盖。

最终存储按用户确认：agents只保留总开关，agent_output_configs保持1:1，name/description/allow_text_output独立列、json_schema为字段定义JSON。无配置false，删除定义清策略；没有定义单独true拒绝。先前本地旧013经备份及正式downgrade回012，重新以最终013升级，不改标冒充迁移，不改写已发布012。

## 本轮审计修复

1. SDK普通str处理器可绕过after_output_validate：完整响应按真实调用来源标记文本，防止错误写接受事实／误采用旧失败候选。
2. mixed允许文本不应泄漏随后被拒的响应前缀：完整响应检查及保存后才发布既有text事件。非法Schema、混调、多output的候选文字仅在原始轨迹，SSE及History普通回复均不显示。关闭路径实时增量不变；mixed首正文时间可能晚于供应商首Token。
3. 配置表策略并发：真实MySQL REPEATABLE READ屏障暴露省略策略的Schema/提示词写者可能覆旧值或返回旧值。统一父后子current read，返回同步已锁定的最终只读bool；真实MySQL/PG两类竞争断言返回与fresh物理配置一致。
4. MySQL隐式DDL多段降级：在013首个DDL前检查整条降级路径，提前执行后续012数据丢失保护／011不可逆保护；保留严格012配置的013→012合法降级。拒绝后重新连接核验版本号、物理列和定义零变化，避免只修复重试而留下半执行结构。最终方言复跑单列结果。
