让类型一眼可辨，让复制按需出现

三个方案使用同一组会话、用户和群聊。第一行展示交互状态，其余展示默认状态；可悬停、Tab 聚焦和点击试用。

推荐

A · 悬停显示复制

类型图标放在标题左侧；ID 后的复制按钮在悬停或键盘聚焦时出现，文字不移动。

B · 点击 ID 复制

不放复制图标。ID 本身是按钮，悬停时高亮并提示“复制会话 ID”。
