## 实现

- 会话概览：指标、提问趋势、Agent 分布、活动列表四分区独立读取，最多两并发，分区完成立即替换所属区域；保留顶部筛选与其他完成区域。活动列表仍一次批量补齐账号资料，不为每个图重复查询账号。
- 复用现有 `/api/v1/diagnostics/sessions/overview`，增加 `section=all/metrics/trend/agents/activity`。GET／POST均支持，默认 all 保留完整响应；所有模式保留管理员校验和 no-store，无效分区422。
- 分区错误就近显示且可单独重试；旧筛选／路由请求取消，检查请求代次防止迟到覆盖。未完成或含失败概览不能作为完整快照恢复。
- 用量：趋势／汇总与明细并行，明细先到即可展示并加载贡献会话；错误和重试按区域独立。报表晚到不清除当前图例焦点。ResizeObserver 在同尺寸、同宿主时不重复绘图。
- 用量明细只计算所需分组及汇总，避免生成全部分组与趋势；贡献会话不再查询未使用的模型和 Agent 元数据。
