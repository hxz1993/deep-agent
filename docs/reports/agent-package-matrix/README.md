使用 4 个受控进程，每个进程串行执行。每例数据与其他例隔离，不访问公司环境或真实业务数据，不调用模型或 MCP 网络接口。启动及结束对 `src/deep_agent` 全部 Python 文件、迁移 `005` 和矩阵脚本计算 SHA256；指纹改变时不能标记完整通过。
