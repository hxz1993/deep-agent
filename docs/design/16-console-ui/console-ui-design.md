# DeepAgent Console 轻量企业控制台设计

> 状态：当前有效
>
> 生产入口：`/console/`
>
> 记录基线：`feat-ruge-0818-console-ui`，2026-08-21 工作区版本

## 1. 设计目标

Console 面向企业管理员和 Agent 开发者，用于配置、联调、运行检查和问题定位，不是营销首页，
也不是最终业务用户的聊天产品。重构需要同时满足：

- 保留旧 Console 的全部真实前端入口、状态和错误语义。
- 提升配置对象的可扫描性，让 Agent、Skill、工具包和模型不再依赖密集弹窗。
- 对话测试保持内容区聚焦，运行信息进入连续检查器，不与正文争夺注意力。
- 在四套主题、桌面、中等宽度和窄屏下保持一致的信息层级。
- 不通过 UI 重构虚构后端能力或改变接口字段。

## 2. 视觉语言

当前视觉概括为“企业控制台 + 轻 Bento 卡片 + 高密度业务列表”，带少量 Notion 式克制感。

### 2.1 基础气质

- 浅蓝灰画布承载页面，白色表面承载实际操作区。
- 页面级区域使用较大圆角，控件使用中等圆角，胶囊只表达状态。
- 分层主要依靠背景差、1px 弱边框和很低的阴影，不依赖粗线框。
- 高密度列表保留清晰列结构，但减少纵横网格线和重复容器。
- 紫色只用于主操作、选中和焦点；绿色、橙色、红色只表达语义状态。
- 不使用渐变、重阴影、玻璃拟态和营销式大留白。

### 2.2 当前核心 token

| 语义 | 当前值或规则 |
| --- | --- |
| 平台主色 | `#555FFF` |
| 明亮/护眼画布 | `#EDF3F6` |
| 明亮/护眼表面 | `#FFFFFF` |
| 明亮/护眼弱边框 | `#DFE7EC` |
| 页面卡片圆角 | `15px` |
| 控件圆角 | `9px` |
| 顶栏高度 | `58px` |
| 一级图标栏宽度 | `52px` |
| 配置资源栏宽度 | `212px` |
| 页面间距 | 以 `10px` 为基本分栏间距 |
| 页面阴影 | `0 5px 18px rgba(36, 56, 74, .055)` 量级 |

token 通过主题变量继续适配 light、paper、dark、contrast。护眼模式使用暖橙语义点缀，
不使用大面积土黄色背景。

## 3. 全局页面架构

```text
全宽顶栏
├─ 产品图标 / DeepAgent / 当前页面面包屑
└─ 连接状态 / 四主题切换 / 用户与版本信息

左侧一级图标栏
├─ 对话测试
├─ 配置中心
├─ 诊断入口
└─ 接口文档

主内容
├─ 对话测试工作台
├─ 配置中心资源页
└─ 诊断页
```

- 顶栏优先占据整行，一级图标栏从顶栏下方开始，避免品牌图标与页面导航争抢第一视觉层。
- 一级图标只显示图形，悬停或键盘聚焦时显示 Tooltip。
- 产品版本和数据库结构版本收进用户浮层；顶栏连接状态只保留轻量状态标记。
- 一级导航切换不重新加载页面，保留当前前端状态。

## 4. 对话测试

### 4.1 桌面布局

```text
可选 Agent 列 | 会话列 | 对话主体 | 连续 Run 检查器
```

- Agent 列默认收起，通过无边框图标 + 下拉框切换；需要浏览时可固定为独立列。
- 会话列、可选 Agent 列和右侧检查器支持拖拽调整宽度。
- 当前限制：Agent `150–280px`，会话 `220–420px`，检查器 `260–460px`。
- 对话标题栏与右侧检查器在视觉上连接，标题操作延伸至最右侧。
- 窄屏下 Agent、会话和检查器转为抽屉，页面不产生横向滚动。

### 4.2 对话呈现

- 用户消息保留气泡；Assistant 使用透明、全宽正文，不显示机器人头像。
- 一个 user 到下一个 user 之间的连续 Assistant 历史合并为一个可视回答，Checkpoint 边界除外。
- 最终正文常显；thinking、中间文本、普通工具、Tool Search 和 HITL 进入默认折叠的“处理过程”。
- 单个工具卡仍可独立展开；HITL 折叠标题明确显示“等待操作”。
- pending、cancelled、error、interrupted 保留真实状态；removed 工具立即从界面删除。
- 附件、Context Reference、主动压缩、Checkpoint、分支、重试和取消不因视觉重构被移除。

### 4.3 连续检查器

右侧不再堆叠大表格卡片，而是按运行顺序展示：

- 当前会话和请求 Header。
- 上下文总预算、历史占用、动态输出预估、安全余量、可用输入预算、压缩线和目标线。
- Token 使用使用横向占比条，并同时保留原始数值。
- 最近 Run、工具调用、Tool Search、耗时、压缩和 Checkpoint。

检查器只负责观察，不复制对话区已经呈现的工具过程，也不从历史正文猜测 Run Usage。

## 5. 配置中心

配置中心使用“左侧资源目录 + 右侧内容区”，不使用横向一级 Tab，也不允许页面级横向滚动。

### 5.1 当前分组

| 分组 | 入口 |
| --- | --- |
| Agent 设置 | Agent、模型、内置工具、系统工具、Skill、MCP、UI 工具 |
| 系统设置 | 辅助工具、全局配置、数据库连接 |
| 辅助资源 | 模型目录 |

资源目录激活态使用浅紫背景和图标，不使用整行高饱和色块。

### 5.2 Agent

- 默认提供卡片视图，并可切换为高密度列表。
- 卡片只展示真实字段：名称、模型、能力摘要、Skill 和更新时间。
- 点击卡片或列表行进入独立二级编辑页，不再使用悬浮弹窗。
- 二级页保留左侧配置目录；返回为无边框文字操作。
- 保存和发起测试固定在编辑页顶栏右侧，避免底部重复操作栏。
- 编辑仍覆盖名称、完整 Agent ID、模型、Temperature、System Prompt、工具包和 Skill。
- “默认能力、显式无能力、指定能力”三种语义必须保持可区分。

### 5.3 高密度列表（风格 A）

模型、MCP、系统工具等标准列表统一采用：

- 柔和表头背景，行高紧凑，列宽稳定。
- 只保留必要横向分隔，不绘制完整单元格网格。
- 行 hover 使用极浅底色，首列用 2px 主色提示当前关注行。
- 状态使用浅色胶囊；操作使用统一小按钮或图标按钮。
- 主标题、编码、副标题按强弱两级排版，不把所有属性放进同一行。
- 空状态、加载、禁用、冲突和失败仍在原列表位置反馈。

### 5.4 Skill

```text
Skill 轻卡片列表 | 跨栏标题与操作
                 | 说明/元数据/资源目录 | 文件预览
```

- 左侧 Skill 列表脱离多余外框，卡片展示来源、运行状态和资源数量。
- 详情标题和操作栏跨满内容宽度并以下边框分隔；标题下方再进入左右布局，右侧只用于文件预览并撑满可用高度。
- `SKILL.md` 作为资源目录首项。由于当前 Console API 不披露完整正文，预览只明确展示索引摘要；
  完整正文仍由运行时渐进披露，不能由前端伪造。
- References 与 Assets 选中整行即预览，当前项使用浅紫底和左侧色条高亮。
- 脚本保持“不披露源码”的安全边界。
- Manifest 不再单独占据右侧空间。

### 5.5 UI 工具

- 左侧为紧凑工具包卡片，两行表达图标、名称和编码；状态与工具数量右对齐。
- 代码内置和手工工具包仍分组，选中态使用浅紫背景。
- 新建工具包位于页面主标题右侧。
- 右侧显示当前工具包摘要和工具列表；工具数量较少，不额外占用空间放搜索与状态筛选。
- 编辑工具包、删除工具包、新建工具使用统一图标与按钮规格。
- Agent 仍按工具包整体启用，不把单工具开关误写进 Agent 保存协议。

### 5.6 模型目录

- 搜索、接入渠道、输入模态和查看方式合并为透明命令栏并以右对齐为主。
- 左侧研发方使用紧凑轻卡片，文字和数量垂直居中。
- 模型表格填满剩余内容高度，仅列表内部滚动；分页始终位于内容区底部。
- 标签使用低饱和胶囊，接入渠道使用紧凑图标入口，不为每个操作堆文字按钮。

### 5.7 系统摘要

- 数据库连接使用轻量只读表单，不展示密码、凭证或完整本地路径。
- 产品版本和数据库结构版本进入用户信息浮层，不在资源目录重复展示。
- “辅助工具”承接固定辅助场景的模型映射；具体编辑弹窗仍使用“辅助模型”准确描述保存对象。

## 6. 交互规则

- 32–34px 是常规控件高度；一级图标按钮可使用约 40px 点击区域。
- 纯导航或返回操作优先无边框文字/图标，不与主按钮争抢视觉权重。
- 删除使用红色轻按钮，主保存/新建使用平台紫，普通编辑使用中性按钮。
- 图标必须提供 `title`、`aria-label` 或可见文字；图标本身通常为 14–18px。
- 列表选择、资源预览和目录切换必须即时反馈，不能依赖整页刷新。
- 需要保存的表单保留未保存提醒、校验错误、冲突和成功 Toast。
- 四主题只改变 token，不改变页面结构和信息顺序。

## 7. 响应式规则

- 宽桌面：完整资源栏、会话栏和检查器并列。
- 约 `1260px`：检查器转抽屉或默认隐藏，保留显式打开入口。
- 约 `920px`：Agent 固定栏退出主栅格；配置资源栏收窄。
- 约 `760px`：会话、Agent 和检查器使用抽屉；配置资源目录转紧凑导航。
- 任何断点都不允许页面级横向滚动；大表格只在自身容器内滚动。

## 9. 不可破坏边界

- 不改变后端 REST、SSE、History 和权限契约。
- 不删除取消、分支、重试、附件、Context Reference、主动压缩、Checkpoint 和 HITL。
- 不从 UI 推断或生成后端不存在的字段。
- 不在 Console 中展示密钥、凭证或完整本地路径。
- 不把临时原型、浏览器截图缓存或本地数据库提交到仓库。
- 原型与本文档发生冲突时，以已验证生产代码和真实功能为准。

## 10. 视觉验收清单

- 顶栏、图标栏、资源栏和主内容层级清楚，无重复品牌或版本信息。
- 页面卡片间距一致，圆角、边框和阴影来自统一 token。
- 表格列宽稳定，操作按钮统一，不出现过密网格线。
- Agent 二级编辑、Skill 预览、UI 工具和模型目录均无页面级横向滚动。
- 工作台分栏可拖拽，最大最小值生效，窄屏抽屉可关闭。
- light、paper、dark、contrast 均保持可读；语义色不被主题背景吞没。
- 纯 UI 调整至少运行相关 JS 语法检查和目标 Node 测试；大范围改造再执行完整浏览器回归。
