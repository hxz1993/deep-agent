本次方案有一个总开关、一份组合JSON Schema，0.14.3新增“允许文本输出”二级选项（默认false）：总开关默认关闭，关闭沿用旧逻辑；开启后以一个输出工具提交结构，各顶层字段可选，可同时出现，允许全部不必须及空对象。不按对话轮次更换工具定义。

开关放agents，新配置表只保存定义，012同时增加更新人。输出不加入capabilities，UI Deferred仍保留。普通/MCP工具事实不由模型结果替代，客户端仍负责业务状态、修订、授权和保存。

安装只保留一种导出：关闭完全不带新增输出键/文件，保证旧版可导入；开启携带完整配置，旧版允许拒绝；旧包导新服务默认关闭，包括覆盖目标原来开启的情况。新版导入容忍安全未知扩展，已认识的必需内容和ZIP安全规则仍校验。跨版本必须用真实导出物和冻结旧服务完整安装验收。

Console仅通用JSON/正文，有“完整JSON/按结构分组”，失败与成功尝试统一标“输出”。公共SSE、History和持久化同步定义，不仅服务Console。

三方两轮确认可接入，无剩余设计阻碍；BOM早期保留bom_turn_v3根包（业务后续调整由BOM课题维护），租赁保留合同/补丁/澄清/复核及文件引用。客户端仍需由用户另行安排适配；租赁首版采用过程进度＋accepted后完整显示，不计为保留原字段级预览。平台实现与验收不替代客户端业务适配，不发开工通知。

旧稿的多个互斥输出工具和契约组已经由本次设计替代；0.14.3按用户确认新增显式文本策略，与JSON required分开；0805实验代码/旧迁移不恢复。历史全文从Git查看，当前实施以本目录完整设计为准。
