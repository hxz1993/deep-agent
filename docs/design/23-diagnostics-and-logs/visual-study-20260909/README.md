## 已确认的信息架构

- 诊断中心下只有“日志”“会话”两个平级独立入口，不增加第二侧栏。
- 日志为紧凑内容行，结构化枚举用胶囊；长文本与规范字段放右侧只读抽屉。
- 会话主页合并统计与排查，支持概览/列表两视图；按Agent、时间、用户等筛选。
- 两视图打开会话均进入完整只读详情，复用对话测试的对话/轨迹与右侧统计，不提供写操作。
- 日志与会话通过Session/Run双向定位；诊断运行日志不代替会话轨迹、不复制正文。
