# v0.10.9 管理删除与回归审计

本轮复审基线为 v0.10.7（5e0c78b）和 v0.10.8（a8c213a），并复审本轮全部改动。无数据库迁移，Head 保持 006。

| 项目 | 结果 |
| --- | --- |
| Agent 有历史会话不能删除 | 改为初次确认后显示本人、其他用户及总数，再用红色按钮确认级联删除；范围变更再次确认 |
| 渠道有历史台账不能删除 | 确认绑定、运行记录数量后删除渠道台账；Agent 和聊天历史保留 |
| 删除与正在执行/落盘冲突 | 本实例阻止同资源新运行，等待流式、同步聊天、手动压缩收尾和后台写入后再删；失败或超时不执行删除事务 |
| 旧持久化错误阻碍删除 | 删除专用 flush 等待收尾但允许越过既往错误；正常聊天仍严格报告写入失败 |
| MCP 删除引用竞态 | MCP 与 Agent 关联写入使用父锁，并在删除事务内复核引用；重命名统一锁序 |
| UI 单工具删除与移动 | 按实际选择判定引用；防止移动留下显式选择悬空 |
| 损坏 Web Search 配置不能修复 | 后端允许提交新草稿；Console 保留运行配置并提供重新配置入口 |
| 缺失 Skill 无法解除关联 | 已选失效项允许关闭，关闭后不能重新选中 |
| v0.10.7 | UI 实现未发现新增确定缺陷；修正旧测试中的 Tab 顺序断言 |
| v0.10.8 | 搜索匹配、精确名称缺失、SDK 披露及持久化续跑回归通过，未发现新增确定缺陷 |

验证：Console 全部 621 项通过；后端按删除、真实 SDK 取消、手动压缩、事件持久化、Web Search、UI 和 MCP 引用分别定向回归通过。删除完整 11 项及 ActiveRun 5 项最终合跑通过。事务异常回滚、不同所有者计数、影响范围变化、管理员权限、渠道改绑后的遗留 Binding 清理均有行为测试。

浏览器在隔离 SQLite + 真实管理 API 上验证两次确认、取消不删、实际级联删除、红色按钮及默认聚焦取消；渠道删除后回读确认 Agent 和聊天历史保留。未删除现有业务数据。临时服务和自动化浏览器验收后关闭。

验证边界：真实 MySQL/PostgreSQL 并发行锁套件因未配置隔离环境而跳过；本轮不声称生产数据库并发验收通过。运行取消沿用单 API 实例部署边界，没有新增跨 Pod 取消能力。仍被渠道引用的 Agent 需要先改绑或删除渠道，停用不解除引用。
