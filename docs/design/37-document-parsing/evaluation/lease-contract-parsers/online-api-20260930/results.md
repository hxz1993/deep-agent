## 初步质量核对

已对照已有物理页7–10人工基线，抽查五个提成租金阶段的日期/比例、物业两档条件、管理费/保证金等信息；上述关键数字可在两份产物中找到。尚未进行全部31页逐块评分，也未执行下游业务字段提取，不能称整合同100%准确。

重新渲染并肉眼核对物理页7与9，确认：

- Paddle第7页：印章遮挡区域的1.1条款被拆散、部分文字遗漏并重复，正文与印章文字混杂；下方装修押金条款把原件的“交付之前”识别成“交付之日起”，会改变付款时点。
- MinerU第9页：营业额列举出现重复块和额外错误文字；同一银行账号被输出两次，其中一次数字不一致。原件只有一处账号。不能让业务模型盲目选择一个值。
- 两份产物都保留了第8页到第9页的结算日期断句。后续字段抽取要沿原始页序衔接，不丢页首续句；本次未以此证明自动跨页合并已成功。

第一轮表明两家足够进入正式合同质量比较，但不能仅凭榜单或关键数字命中率直接定最终供应商。先补充逐页/表格/金额/日期与付款条件的人工评分，再比较是否需要替代解析或原图复核。

## 费用与其他候选

本轮使用MinerU官方服务和Paddle AI Studio入口，未调用百度智能云0.05元/页商业接口。返回体没有费用账单，记录为免费入口测试，不把商业标准价1.55元算成本轮实际扣费。

Logics提供[官网](https://logics.alibaba-inc.com/parsing/)及[官方魔搭Demo](https://www.modelscope.cn/studios/Alibaba-DT/Logics-Parsing)，当前未找到公开生产API/Key申请入口。

DeepSeek官方模型API与开源OCR2不是同一已核验的托管服务；目前官方价格/模型文档未列OCR2。国内[硅基流动Key入口](https://cloud.siliconflow.cn/account/ak)的[多模态文档](https://docs.siliconflow.cn/docs/userguide/capabilities/multimodal-vision)列出`deepseek-ai/DeepSeek-OCR`，不是已确认的OCR2。同一硅基流动平台Key可用于其可用模型，但DeepSeek官方Key不能据此用于硅基流动。不从本地8000借用不适用服务的Key，也不静默改成普通Vision模型冒充OCR2。
