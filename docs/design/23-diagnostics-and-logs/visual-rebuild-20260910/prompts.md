# 诊断中心 · DevBox 视觉重构

本轮使用内置 imagegen，不使用 CLI。模板：`UI Screenshot System / UI 截图系统`（`ui-screenshot-system`，案例 17、2、4）。生成的图片是布局主稿，不作为生产页面背景；生产页继续使用真实接口和可操作 DOM。

以下记录初始生成要求。图片生成后的实际尺寸以保存的 PNG 为准，落地时已逐项测量：主标题40px、日志顶栏44px / 右栏436px、会话指标114px、图表254px。不能把初始提示词中的32px标题或36px控件当作最终成图测量值。

日志主稿另做了一次定向图片编辑：保持全页结构、色彩及左侧日志不变，只将右侧会话 / 执行字段改成标签在上、值在下，保留两个主要ID的复制和打开 / 筛选操作；技术区折叠，不生成横向键值表或重复 JSON。

## 共用约束

以用户补充的 DevBox 启动台、DeepFOS 新建中心两张页面为视觉依据。1536 × 1024，正面完整网页内容截图，不画浏览器、不画设备、不画全局导航。冷灰蓝画布 #EDF2F6，白色工作区，深蓝黑文字 #1C2738，次要文字 #68778D，主题蓝 #326FE8。32px 页边距，12px 容器圆角，1px #DFE5ED 边界，轻微投影。中文无衬线字体，主标题 32px、正文 13px、说明 12px；数字用清楚的等宽风格。纯净、清晰、严谨，避免全页极小字号、密集表单、大片紫色、装饰插画和虚构操作。仅平台用户名，不画头像或邮箱。

## 日志

生成可直接落地的高保真「日志」桌面页面。顶部左侧蓝色小方块和字距较宽的 DIAGNOSTICS；下方标题「日志」，副标题「查看会话执行过程，排查运行问题。」。顶部右侧为单行 36px 筛选工具条：最近24小时、全部来源、全部等级、搜索日志内容、筛选图标按钮、蓝色「查询」按钮、刷新、重置；控件内直接表达用途，不额外放字段标题。

顶部下方一个白色圆角工作区，左右分栏，左侧占约 76%，右侧详情占约 24%。工作区顶部小字「查询结果」及「已加载 200 条」，右侧淡色查询时间范围。主体日志每行 28px，不画表格表头、逐行边框、状态圆点或箭头列。每行：灰色时间、INFO/WARN/ERROR 小胶囊、API/网关小胶囊、深色日志内容、最右缩略 Session ID。内容包括「收到用户消息，开始处理」「模型请求已完成」「工具执行完成」「模型请求超时」。一条超时行选中为淡蓝底。行间主要靠排版对齐，主题色只用于胶囊、选中和少数操作。日志填满主要区域但不胡乱添加摘要图表。

右侧详情顶部标题「日志详情」和关闭图标，下方 ERROR 胶囊、时间、重点摘要「模型请求超时」。结构以分组小标题、标签在上值在下展开：会话 / Session ID 及仅复制与打开小图标，Run ID 及复制与筛选小图标；执行结果 / 模型 deepseek-v4.1-flash、耗时 30.0s、尝试次数 2、原因「请求超时，请稍后重试」。下方「技术信息」默认折叠。不要在所有字段上加复制，不要大号跳转按钮，不要 JSON。详情内不画一堆小框。底部左侧「已显示 200 条」，右侧细致的「加载更多」。图片只含单一完成态界面，无额外示意箭头或注释。

## 会话概览

沿用日志主稿的画布、字体、间距、控件和蓝色，生成「会话」概览页。页边距32px，顶部蓝色 DIAGNOSTICS 小字、32px「会话」、说明「了解用户提问与使用情况，查看完整会话。」。右上「概览 / 列表」分段切换，概览选中。第二行右侧一排轻量筛选「全部 Agent」「最近7天」「全部用户」「全部来源」和刷新，不增加外层容器或字段标题。左侧可显示本次日期范围。

四个并列白色指标卡，高约108px，间距16px，每卡左侧柔和粉彩方形图标，深色大数字，清楚中文标签：会话数 128、提问数 486、活跃用户 24、含异常会话 6。不添加同比、成功率等未实现数据。下一行两张白色图表卡：左侧占65%「提问趋势」，蓝色折线与极浅蓝面积、必要灰色水平参考线、9/3至9/9日期，清楚数值；右侧「Agent 分布」，三条横向细条蓝色/紫色/青色，名称「企微助手」「报表分析」「知识库助手」，计数286、124、76。

下方左侧约65%为白色「最近提问」面板，右上小「查看全部 →」。横向轻量列表每行66px，左侧柔和蓝色问答图标方块，提问正文，次行 Agent · 用户名 · 时间；不画头像与邮箱。问题示例「帮我分析本月费用与预算的差异」「查询华东区域第三季度收入」「这份报表中的毛利率如何计算？」「整理最近一周的销售数据」。右侧上方「最近异常」，2条淡红小异常图标与原因、Agent和时间；右侧下方「活跃用户」，用户名与提问数，最多5行。精确网格、深色文字、克制边框、舒服但不过大的留白，无营销插画。
