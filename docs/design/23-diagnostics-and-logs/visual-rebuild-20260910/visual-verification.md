# 诊断中心可重复视觉验收

本目录的三个 `*-master.png` 是视觉主稿；`visual-fixtures.mjs` 只供浏览器验收脚本使用，不会被生产 Console 或后端加载。

## 运行

在 DeepAgent 仓库根目录、已有 `8000` 静态服务运行时执行：

```sh
node tests/frontend/console/diagnostics-visual-review.mjs
node tests/frontend/console/diagnostics-visual-review.mjs --mode live
```

默认从现有 Node/npm CLI 缓存寻找 Playwright 和已安装的对应 Chromium，不下载浏览器、不安装依赖。如本机运行时位置不同，可显式传入：

```sh
node tests/frontend/console/diagnostics-visual-review.mjs --playwright-path /absolute/path/to/playwright/index.mjs
```

默认截图为与主稿一致的 **1536×1024 主内容区域**；浏览器视口默认 1736×1024，为左侧导航保留 200px。脚本通过实际主内容尺寸校准视口，不注入覆盖页面布局的 CSS。

可选参数：

- `--screens-only`：只保留截图与基础视觉检查，方便调样式时快速重复。
- `--out-dir <目录>`：指定截图与测量报告目录；默认 `output/playwright/TMP_to_delete-diagnostics-visual-review-*`，中间验证后可清理。
- `--theme light|paper|dark|contrast`：调用页面已有主题存储，不改生产文件。
- `--viewport 1100x900`：检查窄屏；截图保留实际内容宽度，不强行拉伸成主稿尺寸。
- `--url http://127.0.0.1:8000/console/`：只允许回环开发服务。

## 隔离边界

Fixture 模式拦截所有 API 回包，只返回明确合成的账号、128 个会话、486 条提问和 240 条日志。浏览器业务时间固定为 `2026-09-09T16:00:00.000Z`，不会覆盖真实模式或定时器。跨日问题数、筛选、列表分页与账号下钻可重复；`@invalid.example` 邮箱及不可用头像专门用于证明页面只显示用户名且不请求头像。

页面仍加载当前真实 HTML/CSS/JS，不替换生产渲染器、不贴图冒充页面。所有非 GET/HEAD 请求、外部网络请求均被阻止并计入报告。不会提交会话、启动模型、安装工具、发送渠道消息或写入数据库。`live` 模式不拦截同源 GET 的真实回包，但同样禁止写请求；仅检查已保存页面，不打开附件或借用其他账号身份。

脚本在 `finally` 中关闭 Context 与 Browser，并处理 SIGINT/SIGTERM。报告不保存认证 Header、Cookie、Token 或接口正文；真实模式也不把会话 ID 查询参数写入请求清单。

## 验证范围

- 日志、概览、列表主内容截图；日志高级筛选浮层与只读会话详情补充截图。
- 页面主区、标题、工具栏、卡片、图表、表头、行、抽屉、分页的 DOM 位置、字号、颜色、边框、圆角及相对主稿差值。
- 无横向页面溢出，日志紧凑行高，桌面主要内容区与分页可见，主要字号有可读层级。
- 用户区域只显示用户名，不展示头像或邮箱，不产生头像外部请求。
- 日志只有 Session ID、Run ID 可复制；技术字段默认折叠，展开后也没有泛滥复制操作。
- 下拉键盘开关/外部关闭，筛选查询，Session ID＋Run ID 精确过滤，日志加载更多游标。
- 概览/列表固定时间和公共条件保持，名称搜索，分页稳定切换，最近提问定位精确消息，“查看全部”只进入带条件列表。
- 列表第二页的独立滚动容器滚动 300px 后进入详情，返回必须保留第 2 页及原滚动位置；数字页码与前后页均覆盖。
- 详情无输入框、上传、可交互工具部件、跳日志追加入口；未产生执行请求。
- 真实模式在当前范围有会话时打开第一条，确认 History GET 成功、只读边界及返回列表；不将真实正文或完整 ID 写入报告。

## 证据解释

`review.json` 保存实际检查结果与尺寸，`README.md` 是结果索引。**行为和字号边界通过不代表视觉主稿完全一致。** 必须再把对应页面截图与主稿并排查看，逐项复核标题位置、控件体量、留白、网格、字号、配色和抽屉字段密度。

主稿数据与浏览器夹具不逐字相同，图片生成过程中的不一致统计数值不会成为 API 口径；对照使用相同画布与布局，不伪造生产数据以“凑图”。
