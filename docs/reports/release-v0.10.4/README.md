# DeepAgent v0.10.4 发布审计

2026-09-15。基线为已推送的 `v0.10.3`（`3c02326bdaa0dd1226cf130b82108cf73d82c61f`），审计其后全部改动。用户要求先保存本地提交，再审计修复、提交推送并打 `v0.10.4` 标签；第一笔本地快照为 `d6a6568`。发布分支为 `test`。

## 审计范围

- Console：Markdown 解析与净化、GFM 表格和原文复制、代码块折叠/换行/复制、公式/脚注/提示块/Mermaid，主题、字号与静态资源加载。
- 会话：新对话空态、Agent 名称、调试上下文同步、输入栏位置、会话 ID/复制、提问与会话图标、轨迹轮次分隔、诊断定位和返回。
- 配置：Agent 四类能力计数、卡片/列表一致性、列宽与未配置状态。
- 后端：模型 HTTP 流观察的透明性、计时器与取消/关闭、白名单日志及隐私；沙箱字体注册、默认绘图与产物、普通 Python 启动开销、字体和许可证随源码归档。
- 交付：版本单一来源、缓存导入链、指南和许可证、测试、部署源码归档、工作树和远端分支/标签。

## 审计发现与修复

- 复查脚注跳转发现同类外层滚动问题，限制为最近正文面板，往返不改变路由和页面顶部位置。
- 重复脚注引用与真实标签 `a-2`、`ref-a`、`label` 会生成重复 ID，改用消息级数字标识并隔离引用/注解命名空间；验证所有回链均指向唯一节点。
- 定向更新 DOMPurify `3.2.4 → 3.4.15` 并补许可证。旧版本处于[官方公告](https://github.com/advisories/GHSA-v8jm-5vwx-cfxm)影响范围，本次新增 MathML/SVG 后同步加固净化边界；并未证明当前 Console 可利用该漏洞，不宣称已复现 XSS。升级来自[官方发行版](https://github.com/cure53/DOMPurify/releases/tag/3.4.15)。
- 统一共享会话模块导入版本，避免同一模块生成不同缓存实例；更新已改动入口缓存链。
- 更新旧的单气泡会话动作测试断言，补充实际卡片/列表能力计数及去重、零配置状态、应用覆盖/平台继承/无应用上下文同步测试。
- 后端增量专项审计未发现额外缺陷；不因模型等待原因未明而猜测性更改业务超时、取消或重试。

## Test 会话卡顿的结论与限制

会话 `3490aa76b5824c878a3cd73112a42ce6` 的链接请求在约 554ms 收到模型 HTTP 200 响应头，此后约 239 秒未取得完成回复、未调用工具，最终由取消 API 停止。下一次提问也进入了模型，未发现会话锁未释放。

此前另建的隔离会话分别重试相同网站，以及无工具且只要求回复 OK 的请求；两者均收到模型 HTTP 200 后长期等待，分别在 150 秒和 90 秒取消。临时会话均确认空闲后删除，原会话保留。这些证据表明现象发生在模型回复等待阶段，无法归因于网站读取，也不能据此确定是上游排队、心跳等待还是 SDK 消费过程。

本版增加首字节、字节/块数、等待进度和结束状态，便于后续线上区分网络无数据、仍有传输和消费者等待；计数不是 Token 或正文进度。日志不预读流、不记录正文，不修改业务超时/重试策略。当前没有足够证据确认上游根因，停止重复长时间请求；推送代码不等于已部署 Test，不能宣称线上卡顿已解决。

中文问题确认是绘图字体缺失，Python 本身可处理中文。本版内置 Noto Sans CJK SC 并在 Matplotlib 首次加载时注册；不承诺其他文档/图片库自动采用该字体，它们可显式使用 `FONT_PATH`。
