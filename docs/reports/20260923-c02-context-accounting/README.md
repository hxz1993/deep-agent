普通Console与管理员详情核对累计输入/输出、历史重开、预算进度条和压缩前后值。压缩后旧基准回退原因为`history_changed`；续聊建立基准后，只读状态因未准备完整请求参数标为`history_only`及`request_parameters_unavailable`，不能把此值当完整下一请求预算。

首次对已压缩的小历史再次压缩时，受保护尾部、Evidence及摘要预留无法满足更小目标，安全返回`protected_context_exceeds_target`，未调用摘要或改写历史。追加可压缩材料后成功。

浏览器验收发现并修复成功事件仍引用全量原始历史计数的问题：新事件持久化同次请求前后数值，保留旧字段语义；持久化前直接用同次请求参数调用统一估算器复检。旧事件不迁移、不伪造新口径。另修复未触发压缩的续聊遥测覆盖上次成功压缩数值的问题，并补齐回归。

数据库Head保持006，无DDL；原始Provider Usage不修改。自动触发由隔离测试覆盖，未降低真实环境阈值。
