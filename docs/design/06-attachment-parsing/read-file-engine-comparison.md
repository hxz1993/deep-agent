# read_file 引擎选择与修复验证

日期：2026-10-09。范围是文件读取引擎和预制核验Skill，不修改专业OCR的供应商请求、结果适配或租赁业务，不自动关联已有Agent。

本页保留10月9日的阶段比较。10月10日增加PDF文本层及正式业务回归，实际发布验收以[文件读取、PDF与业务回归验收](file-reading-business-regression.md)为准；下文“PDF保持不动”和“未提交”均为阶段状态。

## 决策

| 内容 | 本轮选择 | 理由与边界 |
| --- | --- | --- |
| DOCX正文 | 固定MarkItDown 0.1.8 | 正文标题、列表、链接、脚注优于旧逐段纯文本；本地读取不启用插件或LLM |
| DOCX元信息 | python-docx补页眉、页脚和署名批注 | 默认MarkItDown漏这些已复现信息，不能直接舍弃；不保证文本框或原始版面完整 |
| XLSX | 修复openpyxl路径 | 保留源类型、编号、NA、错误、缓存值和物理行；MarkItDown默认pandas路径存在类型推断损失 |
| PPTX | MarkItDown本地转换 | 增加已验证的文本、表格、支持的图表数据、备注及幻灯片编号；不声称兼容旧PPT或OCR图片 |
| PDF/图片 | 原有parse_document | 本轮保持不动；不引入第四供应商或默认视觉插件 |
| 文件核验 | 内置file-reading-verification Skill | 用户可后续显式关联Agent，说明选择工具、续读及必要复核，不自动授予权限 |

## 同源比较

答案来自合成源输入及源OOXML/单元格，不把另一引擎输出或模型回答作为金标准。原件只读，真实正文与详细产物位于Git排除的本地私有归档。

- Word：已知样例中旧读取器遗漏链接URL与脚注，默认MarkItDown遗漏页眉/页脚/批注；混合实现保留五类检查点。两个真实Word的835、57个OOXML非空段落（包含表格段落），在旧读取器、默认MarkItDown和新混合输出中均可匹配；这是文本覆盖，不是版面或业务正确率。
- 长Word：旧实现约0.05秒，新混合约0.77秒；正文估算Token约50,406→52,039。24K/48K读取仍为3/2次；此次接入改善结构信息，不承诺更省Token或更快。
- 完整BOM：旧实现误将仅样式空格计入200万格限制而失败。新实现按真实内容格扫描，21表约0.56秒，默认MarkItDown约2.02秒；正文总Token约163,084对225,229，减少约27.6%。27,185个非空源值独立核对等价，不代表183处图片或全部复杂显示格式已识别。
- 20个BOM显示核验点：16项可直接匹配；4项复杂货币格式仍用原值和去重格式引用表达，不伪造显示结果。未知格式字典一次表达，避免每个格附完整格式码。
- 单一BOM工作表离线分页：24K为新实现1次、MarkItDown2次；48K均1次。整个工作簿拼接后的离线分页次数不能当产品调用次数：read_file一次读取所选工作表，读取21表至少21次。
- PPTX：已知标题、正文、表格、备注和编号均保留。真实Runner测试覆盖读取、上下文压缩后再读、新Run重开、跨用户/未附加文件拒绝；超长中文/emoji正文在24K/48K完整包装预算下连续续读重建一致。

## 修复细节与保留限制

XLSX保留CSV引用规则（逗号、引号和单元格内换行）；offset/limit仍为物理行。常见百分比、补零、定点小数与千分位可以投影，显示舍入附原值；未知格式使用去重[F编号]及元信息字典。读取公式缓存，不执行或重算，缺失缓存有计数；合并范围按本次读取行展示，隐藏状态保留。8M解析安全上限和压缩包安全检查继续生效。

本轮没有新增OCR图片提取/渲染链路。Office包含图片时，读取成功并不代表图片内文字已读到；当前Paddle/GLM服务也不能直接接收Office原件。不能因为有图片就把已准确读取的全部数值重新OCR。核验Skill按风险定向复核，不默认双引擎重复调用。

依赖仅增加markitdown[docx,pptx]固定版本；继续维持NumPy 1.x以兼容PyArrow/DeepCube。未启用all extras或OCR/LLM插件。当前虚拟环境复用了系统site-packages，uv pip check未覆盖系统依赖，不能以其缺包提示作为运行故障；实际核心导入与回归另行验证。

私有证据入口：docs/local-artifacts/Report BOM Excel解析对比/read-file-fix-comparison/word-results.json与xlsx-readfile-fix/results.json。使用说明见[文件读取与核验](../../guides/file-reading.md)。
