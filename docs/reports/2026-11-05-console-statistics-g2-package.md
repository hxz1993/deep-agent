使用真实本地 8000 页面。统计页正常读取本地数据库，对部分只读响应人为增加等待及一次 503，以验证加载交错、局部失败和重试；没有修改数据或调用真实模型。

- 会话指标先显示时趋势仍等待；趋势完成后补齐。趋势失败时指标仍可用，重试只再请求趋势。
- 用量主图等待时明细和贡献会话已显示，随后主图补齐；两个页面未见 JavaScript 错误。
- G2 从真实图表 Skill 资料及 Python 入口生成六套脱敏样本：分组柱、堆叠柱、环图、折线、横条、27 图层财务组合。六套均通过真实 G2 绘制及非空像素检查，配置原文一致，流式六卡片均不创建 frame。
- 实际悬浮提示将含 HTML 的分类名作为文字显示，没有创建图片节点；frame 的 CSP 不含 unsafe-eval、网络连接被禁止。窄栏自动适配至 298px，移除卡片后 frame 全部释放。真实布局调整存在库本身的短暂防抖，验收等待尺寸实际同步，不用固定 250ms 判断成功。
- 非内联远程数据配置被拒绝且保留原文；本地预制包接口及页面数据已显示 V124。

浏览器使用界面当前主题及本地图表资源，验证不是客户浏览器／低配机器性能保证；没有进行客户网络或真实业务数据结果验收。统计查询的 MySQL／PostgreSQL 执行计划未实测。
