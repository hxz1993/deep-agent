# 文档解析生产接入回归约定

- 本轮用户显式授权复用历史提供的三家解析Key，以及只读本地已配置的同一个DeepSeek模型做固定参数提取。Key只驻留受保护进程输入/内存，不写源码、报告、日志或环境变量；GET配置仅验证脱敏状态。
- `local-private/`保存授权原件引用、人工原图答案、供应商原生响应、任务与模型轨迹，必须被Git忽略。所有可提交内容仅含脚本、协议和脱敏汇总；不修改租赁Demo、不保存线上合同或付款计划。
- 在核对供应商输出前建立原图事实，不用旧模型输出当答案，不向待测OCR/模型发送金标准。局部字段命中率、严格表格坐标、全文完整性、付款金额正确性分别报告。
- 使用产品生产适配器、缓存读取器和共用24K/48K预算；真实LLM隔离包装必须使用`build_document_toolset`的正式工具描述与参数Schema，不另写简化说明。供应商原生正文/表格不改写或业务纠错。
- 同一已提交任务仅恢复原task查询或下载；提交未知不可盲目重POST。保存每次attempt元数据，恢复时间与首次云端生成时间分开；无可靠计时不能推断首次速度。
- 真实模型完整读取由ToolReturnPart的页码、字符位置与原生正文逐字符覆盖验证，不以最后has_more=false判通过。超长单页必须原样使用next_read中的offset和char_offset；保留首轮漏读及复测轨迹。
- 历史ZIP重放必须核对旧任务源Hash与当前原件Hash，单独trial标为historical，不统计成本轮远端解析或时延，也不触发新的云端解析。独立测速作为新的实验明确记录，不把失败任务重提或恢复耗时算作首次生成效率。
- Office真实格式按授权已知答案样例验证；不能把改扩展名或RTF算DOC/PPT/XLS。未找到有效样例或服务没返回须明确未验。
- 临时原图核对渲染标记`TMP to delete`并收尾删除；测试浏览器、进程、临时缓存均主动清理。受保护复核证据保留，不随临时截图一起删除。
