# 思考强度配置原型

2026-11-07 · 交互评审，未实施产品功能。沿用当前 Console 的导航、公共主题、字体、Lucide／品牌图标、32px 控件及紧凑弹框。

本地预览：<http://127.0.0.1:8031/>。顶部切换四个主要界面及改动汇总。此服务只提供本原型和所需的公开 Console 静态资产，不提供产品 API。

## 可直接尝试

1. **对话选择**。点输入框右下的模型，再点底部 Thinking 打开档位菜单。默认勾选「默认」。选「超高」并模拟发送，右侧模型名后显示「 · 超高」。
2. **模型差异**。Qwen3.8 Flash 显示三档，GPT-6.1 Sol 显示五档。切换到 Kimi K2.6 或 Gemini 2.5 Pro 可以体验只有「默认」的情况。
3. **模型目录**：包含上一轮公开快照的 154 条过滤记录，可切 Provider、搜索、翻页。模型目录为只读预览。从「模型配置 → 从目录添加」选择模型时，原生档位随模型能力预填。
4. **模型配置**：点击模型行或铅笔，点档位后的铅笔，在原行粘贴 `["low", "medium", "high"]` 或 `low, medium, high`。点勾号确认这一行，点叉号取消。整个弹框的保存仅改浏览器本次内存。
5. **手工兜底**：选择 OpenAI Compatible 的私有模型，填写原生档位后保存，再回对话选择该模型，即可看到新候选。重复值按首次出现去重，不逐个添加字符串。
6. **Agent 默认**。在同一个下拉框里选择模型和档位，保存后回到对话查看回显。切换模型时重新按该模型选择档位。
7. **历史兼容**：左侧「旧会话」的概览只显示原模型名。继续对话时，输入框按当前 Agent 默认解析。

页面刷新会重置所有演示状态。原型没有发起真实聊天、目录更新或配置保存请求，不修改 8000／8010。

## 补齐的语义

- 当前轮显式指定 → 默认模型匹配时的 Agent 默认 → 供应商默认。
- 下拉框直接呈现生效档位。显式点击「默认」选择供应商默认。切回 Agent 配置的模型时恢复该 Agent 的档位。
- 侧边菜单使用模型原生档位。只有开关或预算控制的模型在 Thinking 行显示「默认」。
- 当次模拟发送的具体档位只在右侧模型名后回显。默认和旧会话只显示模型名。
- 模型只有能力声明，不能在此配置产品默认强度。目录可用则预填；手工覆盖与“恢复目录值”分开，普通刷新不默默覆盖手工声明。
- 手工编辑声明模型接受哪些值，不配置新的参数名或协议映射。未知私有网关的请求适配仍需后续按实际接口验证，不能把填写成功当服务兼容验收。
- 手工修改使 Agent 已有档位失效时，提示重选；不自动把 max 换成 high，也不拿其他模型的默认套用。

## 是否保存历史强度

已核对官方源码和当前本地学习仓库：

| 项目 | 事实记录 | 来源 |
| --- | --- | --- |
| pi 1.5.0 | `ThinkingLevelChangeEntry` 与 `ModelChangeEntry`，沿当前会话路径恢复设置 | [session-manager.ts](https://github.com/earendil-works/pi/blob/v1.5.0/packages/coding-agent/src/core/session-manager.ts) |
| DeepSeek Harness `66491b05e3f0` | `request/header` 的 config 含 reasoningEffort，历史可重建请求配置 | [request-header.ts](https://github.com/deepseek-ai/deepseek-harness/blob/66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db/packages/core/session/src/request-header.ts) 及同仓 core/session/src/types.ts、agent-loop 测试 |
| OpenCode `014614d35b39` | Session model 保存 variant，切换发布 ModelSwitched；variant 可承载思考预设，不等于原生 effort 全量快照 | [session.ts](https://github.com/anomalyco/opencode/blob/014614d35b397775e5d397a490fc72368c894ec2/packages/core/src/session.ts) |

首版建议只保留已有模型行上的当前档位回显。若将来需要刷新后回看具体档位，可以在已有助手消息事件里增加一个可选值，通过原有会话投影读取。工具暂停后恢复同一轮所需的配置，应按续跑需求单独评估。
