# 渠道统计 HTML 原型

2026-09-14 评审快照：当时选定方案为 **图片 A 整体布局 + 图片 B 的列表头像**。只使用静态示例数据，不调用 API 或模型。

- 上方保留单渠道账户切换、账户与应用信息、统计及活跃用户排名。
- 下方采用 A 的平面表格与右侧会话列表：减少边框，单条竖线分隔左右，以留白和字体突出最近会话。
- 左侧两行姓名／ID 与最近会话 ID／提问；增加头像底座，单人图标代表用户，多人图标代表群聊，末列图标打开最近会话。
- 右侧顶部显示姓名、原始 ID。最近与历史会话采用同一套两行样式：第一行复制图标、ID、提问数、时间；第二行最后一轮问题。取消状态及“最近会话”标题，最新一条仅有“最近”标签与稍大的字体／间距，无固定比例高度、底色或回复摘要。
- 切换账户、用户／群聊、姓名查询示例、搜索、选择成员、复制会话 ID 可交互。打开会话仅提示正式实现复用现有详情，不继续实现轨迹原型。
- `index.html`、`sidebar.html` 共用当前原型。外层“只看渠道”入口与原有过滤示意保留。
