状态：2026-11-06，在 0.15.13 基线上完成验收，随 0.15.14 发布；数据库 013、依赖均未变更。

## 改动范围

- ChatGPT 订阅连接使用 `openai_reasoning_summary="auto"` 请求摘要，不设置思考强度。
- OpenAI 和 OpenAI Compatible 模型增加显式「API 协议」选择。缺省仍为 Chat Completions；`tags` 中的 `openai_responses` 选择 Responses。仅在已有 `reasoning` 能力时请求摘要，不按名称或地址猜测。切换协议保留原有 Chat 兼容标记，Responses 不应用这些标记。
- StepFun 的流式用量按累计值更新，重复累计值不相加；缺少用量的后续帧保留最后有效累计值。其他 Provider 不改变此语义，视频映射继续保留。
- 已保存的历史事件不回写、不重算。开发 Skill 同步说明并重新构建。
