## 变更与影响边界

- 千问兼容仅在显式 Alibaba Provider、模型名为 `qwen3.8` 或以 `qwen3.8-` 开头时启用。SDK 出站阶段将简单 `type:[T,null]` 转为等价 `anyOf`，保留类型约束、枚举、常量、注解、默认值与引用展开。已有复杂组合不额外改写。
- 普通工具和输出工具共用模型 Profile 入口；不修改原工具 Schema、配置、入站校验、输出身份或历史，不将模型错误返回的字符串强转为数组。错误参数仍经原校验拒绝。
- 保留 SDK 原 Profile 的其他标记、视频适配与传输；同一 Alibaba 入口的 Kimi、GLM、DeepSeek 和其他 Provider 不启用本次转换。测试覆盖匹配及不匹配模型、普通和流式真实 SDK 请求体。
- Skill 引用名称和浮层只展示，移除点击回筛选；顶部下拉仍可筛选。`+N` 阻止冒泡到行导航，整行和键盘详情入口保持；不改安装、维护、关联与授权。入口及动态脚本缓存引用更新到同一版本。
