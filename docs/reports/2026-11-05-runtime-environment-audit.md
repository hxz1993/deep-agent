## 实现与兼容

- `get_current_time(timezone: str = "UTC") -> str` 由业务 Agent 的统一构建入口注入一次。默认 UTC，可指定 IANA 时区，结果保持带偏移的 ISO 字符串；非法或缺失时区数据时返回可纠正提示，不静默回退。
- Console 在运行时目录增加“运行环境” `runtime:environment`，预制目录和 Agent 编辑不再显示通用工具；时间工具不进入 PTC。
- 已知退役引用 `builtin:general` 在现有规范化入口过滤。旧记录读取不回写，创建／编辑／复制、安装、导出及配置恢复复用同一入口；新包不补旧关联，不写运行时分组。未知能力和非法重复输入校验不放宽。
- 补齐默认工具重名边界：UI 工具和结构化输出的保存／预检拒绝 `get_current_time`，既有同名配置运行前明确报错，不自动覆盖或迁移；不扩大其他工具名称策略。
- 保留 Agent 删除二次确认；处理请求时显示模态等待遮罩和转动提示，结束及失败收尾均关闭。确认弹层轻量入场过渡，遵循减少动画偏好。
