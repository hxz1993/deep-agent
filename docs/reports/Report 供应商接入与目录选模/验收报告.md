# 供应商接入与目录选模验收

日期：2026-10-13。开发验收时版本为0.13.2；按用户后续授权，本轮发布为0.13.3（test分支、v0.13.3 Tag）。Pydantic AI保持2.46.0，无新增依赖、环境变量或数据库结构。

## 实现

| 类型 | 运行协议 | 默认地址 |
| --- | --- | --- |
| MiniMax | Anthropic，SDK保留思考块、签名及工具结果 | `https://api.minimax.cn/anthropic` |
| StepFun | OpenAI Chat Completions，使用`max_tokens`，回传`reasoning_content` | `https://api.stepfun.com/v1` |
| Anthropic Compatible | 通用Anthropic | 用户填写 |

品牌供应商下拉按OpenAI兼容、Anthropic兼容、其他协议分组，两个通用类型统一放在底部“自定义接入”组，复用公共下拉的灰色标题、缩进及键盘交互。订阅保持独立入口。官方MiniMax、阶跃Logo用于配置、会话及用量视图，素材出处见`console/assets/provider-logos/SOURCES.md`。

`models.dev`补齐`minimax-cn`、`stepfun`，保留国际MiniMax来源；国内外MiniMax共用Lab和运行类型，但目录来源独立。仍过滤非文本、无有效上下文和废弃模型。使用官方`catalog.json`完成本地正式导入，共193条提供方模型记录、186个模型、11个目录供应商；打开弹窗或保存模型不会触发在线刷新。

## 从目录添加

两个通用供应商可以选择全部已保存的目录供应商，再搜索、多选模型。只复制模型ID、名称、输入类型、上下文、输出上限和标签，目标供应商、地址、Key与协议不改变。默认名称和调用ID均使用目录模型ID。

- 每次打开是新的选择，不回显已有模型，不禁用已有同名条目。
- 切换目录供应商清空勾选；关闭或切页后清理状态，迟到的读取结果不覆盖新弹窗。
- 一次提交中每项只提交一次；成功项标记“本次已添加”，失败项保留勾选并显示后端原因。
- 重名仍由原有后端校验返回409，不覆盖、不改名、不跳过。
- 品牌供应商继续只看自身目录，已配置模型不可重复选择。

目录是配置模板，不能保证目标客户网关提供该模型、支持相应能力；目录中的官方地址不会替换客户地址。

## 真实8000验收

使用同一个隔离Agent，第一轮调用`get_current_time`并回答，第二轮不调用工具、从历史回忆测试校验码。完整经过Runner、SSE和Event Store，随后请求History核对工具及两轮正文。以下耗时为一次本地两轮验收总时间，仅是功能冒烟，不是速度基准。

| 接入 | 已测模型 | 工具调用、流式、历史续聊 | 两轮总耗时 |
| --- | --- | --- | ---: |
| MiniMax | `MiniMax-M2.7` | 通过 | 6.82秒 |
| StepFun | `step-3.5-flash` | 通过 | 4.17秒 |
| Anthropic Compatible，MiniMax官方兼容端点 | `MiniMax-M2.7` | 通过 | 6.78秒 |
| OpenAI Compatible，阶跃官方兼容端点 | `step-3.5-flash` | 通过 | 3.90秒 |

另用真实SDK直接执行确定答案的加法工具（97+163=260）并历史续聊，两品牌均通过。四种接入的Console模型连接测试均成功；并发触发测试入口限流后按原规则顺序重试成功，该限流不属于供应商故障。

真实浏览器检查了协议灰色分组、键盘选择、Logo、MiniMax默认地址、通用地址必填、目录搜索、多选、跨协议选择、关闭重开、来源切换清空、品牌去重。以真实API制造一成功一409：成功项不会重试，失败项保留具体原因；通用Anthropic也从DeepSeek目录成功新建配置。新增配置的客户地址保持不变。浏览器控制台的409为上述预期校验，无其他脚本错误。

已重启8000统一服务，API、Console和8010渠道网关健康。MiniMax与阶跃及其已测模型保留在原本地SQLite，密钥仅由后端配置保存；原有配置和历史不变。隔离Agent、临时通用供应商及测试会话清理，不留无用测试模型。测试浏览器关闭。

## 验收边界

- 真实通过范围仅限上表两个模型及对应官方端点；目录其余模型没有全部收费测试。
- 思考内容与普通工具调用已验证；高级供应商原生工具、结构化输出和多模态不在本轮真实验收范围内。
- 客户网关的模型别名可在现有模型编辑入口调整，目录选模不能代替客户服务连通性验证。
- 真实验收记录保留在本地忽略目录`docs/local-artifacts/TMP_to_delete_provider_validation/`，不包含于Git交付。
