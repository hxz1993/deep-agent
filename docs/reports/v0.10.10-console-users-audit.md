# v0.10.10 用户资料与会话加载审计

审计范围为 `test` 分支上次提交 `7fe5a2e` 之后的全部工作区改动。版本从 0.10.9 升至 0.10.10；Alembic Head 保持 006，无数据库、依赖或部署入口变更。

## 发现与修复

| 问题 | 修复与验证 |
| --- | --- |
| 当前账号返回邮箱等资料时，缺少禁止 HTTP 缓存的响应头 | 复用 NoStoreRoute；成功、401、503 和缺身份响应均验证 no-store |
| 复制成功后再失败仍留成功勾；重复点击可能产生异步反馈竞态 | 重试先清除旧状态，执行期间禁用按钮；组件卸载后忽略迟到结果，新增行为回归 |
| 详情 History 尚未完成就返回，再进入可能永久复用不完整快照 | 未完成 History 重新加载；被中断的上下文与 Run 定位事件按完成标记补读，新增三种恢复测试 |
| 旧界面断言和迁移前账号弹层样式残留 | 更新平台活跃用户、Inspector 用户字段断言，清理废弃选择器，统一静态资源缓存版本 |

资料链路同时核验管理员权限、调用者凭据转发、缓存身份隔离、单用户参数长度与重复值校验、原始数字 ID/UUID 保留、HTML 转义、missing/unavailable 区分和查询取消。未发现需要阻止本次发布的剩余问题。

## 最终 UI 契约

- 列表与搜索候选只显示 Username、邮箱，不显示头像或复制操作；排行榜使用 Username，保留主题底色通用用户图标。
- 详情、当前用户、渠道归属账号悬停或聚焦显示复制图标，复制原始 User ID 后短暂显示勾；不展开 UID，不改变容器高度。
- 当前用户使用原有浅主题底色圆角底座和圆形用户图标；资料缺失显示“未查到”，保留原始 ID。
- 渠道配置仍输入原始 User ID，点击输入框内查询图标才读取资料。结果为浮层，不增加弹框高度；修改输入、关闭、再次查询均隔离旧响应，不改保存行为。
- 排行榜分别叫“平台活跃用户”和“企微活跃用户”；最近提问保持 Username。
