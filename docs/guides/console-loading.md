# Console 加载与静态缓存

控制台保留无构建的 HTML、CSS 和 ES Module 架构。加载优化只调整资源与只读请求的时机，不改变配置值、权限、会话或工具执行协议。

## 页面加载

- 身份和企业管理员校验成功后，只初始化当前一级页面。工作台、配置和诊断首次进入才加载，不再无条件预热。
- 同一页面共用初始化 Promise；快速切页只激活最后选择的页面。切页不停止已经发起的聊天执行。
- 工作台初始化等待既有 Agent 目录启动链，配置页“发起测试”在工作台就绪后选择目标 Agent。
- 首次直达诊断会话详情只加载共享的静态会话模板，不初始化工作台或请求工作台会话目录。模板请求共用 Promise，失败可重试；切页后忽略迟到的挂载。工作台拿独立模板副本，不能从正在展示的会话 DOM 克隆只读详情。
- 配置经典脚本并行下载，使用 `async=false` 保留执行顺序；模板下载失败可重试，已有部分脚本执行后失败需要重载页面。
- 配置初始化只绑定控件，数据由当前标签请求。编辑器依赖的模型、工具和 Skill 目录全部读取成功才应用，不能将请求失败解释为未关联。
- Agent 列表不等待可选的渠道注释。宠物仅加载当前姿态，其余动画按使用加载，失败保留图标回退。

## 数据库检查

`GET /api/v1/database-info` 保持原有管理员权限和默认完整检查。可选 `include_charset=false` 只读取轻量数据库摘要及 Revision，`charset` 返回 `null`，不执行字符集 SQL。

Console 首屏不请求数据库检查；用户资料展开时才取轻量版本，运维页使用轻量摘要。“检查字符集”按钮才请求完整检查，显示加载、结果、错误及本次检查时间，不将未检查或失败显示为正常。

## 静态缓存

- HTML 入口、错误响应、下载和非 UI 文件保持 `no-store`。
- 8 MiB 以内的 UI 脚本、样式、模板、图片及字体使用 `private, no-cache`：浏览器可保留正文，每次使用仍须向服务端校验。
- ETag 来自实际返回文件内容的 SHA256；不能依靠文件长度、修改时间或手工版本参数判断内容未变。匹配返回 304，内容变化返回 200 和新正文。
- 动态导入继续保持版本引用一致，避免同一模块以多个 URL 重复初始化。不使用 `immutable`，不缓存业务 API 数据。
- Range、PDF、ZIP、教程下载和超大文件保留框架原生流式响应，不能为缓存把整个大文件读入内存。

## 验证方法

先做加载、权限、慢请求、失败重试和 ETag 定向测试，再跑 Console／Python 全量及真实浏览器流程。测速使用同一数据、浏览器和固定网络条件，分别记录冷／热加载。

以当前页可操作时间为主指标，同时记录 FCP、请求数、传输量、304 与错误；后台请求收齐不代表首屏完成。发布前仍须在实际网关确认缓存头未被覆盖。本地结果不等于已部署线上测速结果。
