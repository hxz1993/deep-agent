# v0.11.9 跨版本审计

审计日期：2026-09-28。基线为 v0.11.8 `1a9db17`，检查首次 v0.11.9 `77a27a8` 的全部 30 个变更文件及其调用边界，再核验本次修复。版本保持 0.11.9，不新增数据库迁移、不打 Tag。

## 已修复

| 问题 | 修复与验证 |
| --- | --- |
| 扫码授权后停止轮询，凭据过期仍显示成功 | 使用服务端 expires_in 管理前端有效期；到期显示重新生成，authorizedId 同时检查截止时间，后台计时器延迟也不会允许提交过期凭据 |
| 重新生成与取消旧任务并发，快速操作可能占满每用户两个名额 | 等待已知旧任务取消后再创建；取消请求有 5 秒超时；重复生成和关闭使用 generation 防止迟到创建 |
| 公共注册生命周期提取后的残余导入 | RegistrationError 统一从 channel_registration 导入，删除飞书协议模块的间接转导入 |
| 当前指南与旧研究混淆 | 手动关联入口文案、飞书已实现状态和注册生命周期说明同步；历史研究保留日期并链接当前指南 |
| 末尾空白及静态资源更新 | 清除公共注册文件多余 EOF 空行；更新配置资源缓存标识 |
