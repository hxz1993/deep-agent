## 发现与修复

- 渠道配置允许 `settings.wecom=null`，诊断目录现在安全归一化；会话在分页与明细查询之间被删除时跳过失效记录，避免查询崩溃。
- 鉴权失效后清理渠道身份名称、查询词与布局状态；用户候选从输入框按上方向键正确选择末项。
- 会话删除等待服务端成功后更新列表；连续点击进行请求去重，失败保留记录且不会重复扣除分页数量。
- 统一已变更静态模块及导入依赖的缓存版本，避免同一模块载入两个实例。
- 修正旧测试与实际契约的偏差：保留003的十条历史关系测试，增加006孤儿引用与拒绝丢数据降级验证；配置备份夹具使用006；Agent模型允许显式清空；企微标题符合已发布格式。
- 文档更新为当前五列、全部来源、数据库候选、浮层时间和分隔点复制交互；修复相对链接，并明确历史原型及研究快照的适用时间。
