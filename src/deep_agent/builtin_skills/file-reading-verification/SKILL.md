# 文件读取与核验

用于读取或分析文件。先明确用户需要全文、指定字段还是计算结果，按任务读取必要内容。本Skill不授予工具或文件权限；以当前Run实际提供的工具及其格式说明为准。

## 选择读取路径

| 文件与目的 | 路径 |
| --- | --- |
| 文本、CSV、JSON、日志 | 优先`read_file`；CSV的引号、换行与列关系不能只按逗号猜测 |
| DOCX、XLSX、PPTX | 当前`read_file`声明支持时先读取结构化内容；保留工作表、段落或幻灯片位置，不默认整份OCR |
| 带文字层的PDF | 当前`read_file`声明支持时先直接读取；文字层缺失、乱码、图形或版面关系不足时，按任务选择`view_image`原页核验或已加载的`parse_document`专业解析 |
| 扫描PDF、图形、布局或少量关键字段核验 | 主模型支持视觉且提供`view_image`时，直接查看原图或PDF物理页；需要批量文本、专业版面或表格解析时使用已加载且支持格式的`parse_document` |

工具未提供或格式不支持时明确说明缺少的能力，不虚构工具或把文件改扩展名绕过校验。Office中的图片可能未被直接读取；只有当前工具支持访问对应图片或页面时才进一步查看/OCR，否则请求用户提供相关页图。不要假定沙箱能访问附件路径或联网安装依赖。

`view_image(items=[...])`支持授权附件`{type: "attachment", file_id: ...}`、当前Skill图片/PDF`{type: "skill", skill_code: ..., path: ...}`；仅在授权网络能力时支持公网`{type: "url", url: ...}`。PDF用`pages: [1, 6]`指定从1开始的物理页，省略时只看第1页；普通图片不传pages。多图可一起查看比较，保留每张来源。

查看使用当前主模型视觉，不等于OCR或业务核验已通过。模糊数字、字符不能猜成确定事实；标记不确定并保留文件及物理页来源。同一Run连续查看的图片可继续比较；下一轮需要原图时再次查看。若先通过PTC、Python或Skill生成文件，取得File ID后在外层调用`view_image`，不要在PTC里调用，也不要重复写Python抓图或识图。

## 续读与证据

- 小结果直接使用；有续读参数时按返回位置继续，结合已读范围判断是否覆盖所需内容。不要每次重新从头读，也不要重复调用OCR来获取同一解析结果的后页。
- 保留来源定位：文件、页码、工作表/行/单元格或段落。物理页全部返回、`complete`或最后一批无更多内容，只证明对应覆盖/读取状态，不能证明页面内所有文字都识别正确。
- Excel指定单元格按源物理行`offset/limit`定向核对，CSV单元格内换行不能当成新Excel行；需要整个工作簿时按目录读取所需工作表，不能只读默认首表。
- 合同编号、金额、百分比、日期和付款条件会影响判断时，核对提取文字、单位、表头与邻文；发现冲突、手写、异常数值或关键内容缺失时，再定向核验源值、显示格式或原页图。读取OCR输出不等于直接核验原图。低风险概览无需逐字复核。
- OCR未识别到不等于原件不存在；同一工具反复漏识别也不能增加“原件不存在”的可信度。关键字段未确认时标注未知/不确定字符，不用其他编号、相似金额或推测补齐，也不据此代填保存。

涉及Excel单元格定位、计算、公式缓存或合并表头时，先读取[表格核验参考](references/spreadsheet-verification.md)，再按源物理行和列核对。仅在当前Run提供`execute_python`等执行工具且数据已经合法取得时，对明确数据计算或交叉检查；读取一次能完成的工作不额外写脚本。

结果区分“工具返回”“源文件核验”“推断/计算”和“仍不确定”，说明会影响答案的缺口。用户要求分析不等于授权修改原文件或业务数据。
