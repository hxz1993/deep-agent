# v0.13.6 发布审计与验收

日期：2026-10-17（Asia/Shanghai）。仓库 `deep-agent`，分支 `test`；审计范围为上次推送 `c53646a`（v0.13.5）之后全部产品、测试和文档改动。

## 范围与结论

- 网络搜索：DeepSeek独立Search；DeepSeek/Kimi跟随Fetch；历史配置、凭据复用、自定义网关、取消/重试、超大结果和图片边界。
- Console：协议分组、网络搜索与文档解析表单、UI工具包删除确认、时间/耗时切换、真实及历史计时和静态资源缓存。
- 后端：完整流式响应与工具执行计时；UI包无引用时事务级联；普通登录用户模型读取和管理员维护边界。
- 文档：决策API及框架升级研究保留核验日期和未实施状态，使用指南与本轮发布一致；不发布私有响应、合同、配置或数据库。

## 审计修复

| 问题 | 修复及证据 |
| --- | --- |
| 首次云Fetch可能把代理fake-IP当作目标私网IP而拒绝公开网址 | 复用现有代理兼容的公网DNS校验上下文；仍拒绝真实私网。新增首次调用、真实私网拒绝及总期限取消回归，测试先失败后通过 |
| 渠道页面仍通过旧缓存标识导入会话模块 | 统一共享模块及入口缓存依赖，防止同页出现两个模块实例；新增缓存图回归 |
| 已持久化的工具精确结束时间被后续展示SSE覆盖 | 保留服务端执行端点，展示事件不改精确时长；新增持久化→展示事件回归 |

另补真实SDK流式计时测试：首块后继续等待到EOF，用受控单调时钟验证metadata与日志均为32000ms，完成前不提前记录结束。未发现权限拆分和UI包事务级联的其他阻塞问题。
