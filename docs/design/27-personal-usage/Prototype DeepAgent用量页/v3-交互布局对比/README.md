# DeepAgent 用量页 · 三种交互布局

交付文件：`index.html`，单文件 HTML，样式、SVG 图表、示例数据和原项目 Logo 全部内联，无网络依赖。2026-09-23，仅原型，不连接产品接口、不改变数据库或业务逻辑。

## 设计口径

- 沿用 `console/themes.css` 浅色主题主色 `#4f46e5`、文字与边框风格，Logo 使用 `console/favicon.svg`。系列为同色相紫色阶，请求次数为深紫色虚线。
- A 均衡总览：上方双轴日期趋势，下方用途/排名与明细表。
- B 趋势与明细：趋势与分布并排，完整明细表位于下方。
- C 明细工作台：左侧明细，选中行后右侧联动日期趋势及用途分布。
- 仅日期序列使用趋势图。用途、用户等类别仅用构成条、排名条与表格，不将无序类别连成趋势线。
- 左轴为当前 Token 指标，右轴为模型请求次数；请求次数可关闭。数量较多的分组展示 Top3 + 其他。关闭图例仅改变图表，不影响总汇总或明细。
- 三种布局共用固定生成的 30 天示例请求，输入、输出、合计、次数、分组和趋势均由这些记录计算。无真实用户数据。

## 可操作

布局切换；用户、Agent、模型筛选；7/30 天；Token 指标及分组；柱形/折线切换；请求次数叠加；图例开关；图表悬浮、点击固定与 Escape 关闭；表格分组、搜索、排序；详情弹窗；C 方案行选择联动；当前明细 CSV 导出；重置。

## 验证

已通过 JavaScript 语法检查，以及使用轻量 DOM 桩运行脚本的定向静态验证：汇总一致性、三种布局渲染、四种趋势分组、柱形/折线、7/30 天、组合筛选、联动、已删除模型、搜索、排序及空数据；无 NaN 图形坐标。

本地 file URL 被浏览器安全策略拒绝，未尝试其他路径绕过，因此尚未完成真实浏览器视觉与交互验收。静态验证不等同浏览器测试。未启动额外浏览器进程或 HTTP 服务。
