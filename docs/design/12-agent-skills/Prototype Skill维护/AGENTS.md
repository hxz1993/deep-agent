# Skill 维护原型维护约定

- 这是 Skill 课题统一交互原型，后续修改本目录，不按迭代重复生成不同原型。
- 所有交互仅操作独立示例数据；不连接真实 API，不导入真实提示词、密钥或客户材料。
- Skill 是可被多个 Agent 引用的独立资源；分组不赋予唯一所有者，解除关联不删除资源。
- 先复用 Console 公共主题与控件；原型布局放 prototype.css，不修改产品 CSS 来适配原型。
- 新增设计与当前能力分开标注；用途分类和复制替换尚属设计，不凭原型宣称产品已实现。
- 功能落地后清理 HTML/JS/CSS、截图和预览服务，保留设计决策。

- 当前评审范围是Skill执行环境变量；真实详情渲染、CSS、图标通过静态允许列表复用。新增弹窗只在prototype.js中包装，不修改console/源码。
- 示例敏感值不回显、不存localStorage，保存时只保留已设置标志。实际配置、注入、授权及加密均未实现，见上级skill-environment-design.md。
