# DeepAgent v0.14.8 发布审计与回归

日期：2026-10-25。分支：`test`。基线：`v0.14.7`（`9b80dab`）。本报告覆盖自该提交以来的全部源码、Console、测试及设计说明差异；提交标识以最终注释 Tag `v0.14.8` 为准。

## 范围与结论

| 变化 | 核对结果 |
| --- | --- |
| PTC 选择与工具说明 | 按数据交接选择编排，查询结果直接交 Python／Skill、HTML 直接交发布工具；独立小查询可原生调用，不固定唯一代码或调用次数。发现、授权、禁止探测、写入顺序及未知送达不重放约束保留。 |
| 渠道 URL 与 PTC 双入口 | 仅可信渠道 Run 装配 `channel_message`，不因其他来源同名工具扩权。媒体的公开 URL 与已授权 File ID 二选一；先完成整批下载预检再发送，同 Run 串行发送。取消、部分成功及未知送达不伪报成功或自动补发。 |
| 公网下载与代理 | PTC 文件中转、渠道媒体及看图复用有界下载，保留逐跳 SSRF、地址固定、TLS、20 MiB 及工具／渠道自身限制；无平台身份头外传。系统 HTTP 代理与环境变量使用 HTTPX2 相同的发现来源。 |
| 看图与历史 | 先验证实际图片字节，再交当前 Run 的模型；失效图片成为工具失败，可继续选择其他来源。SSE、完整与增量 Event 编码及 History 仅保留 URL 引用，旧 ImageUrl 仍可读，不重写旧事件或存储图片字节。 |
| Skill 请求错误 | 校验失败不回显完整 inputs；工具参数、脚本索引、授权和执行后端保持。 |
| Console | 诊断详情独立按需加载共享静态模板，消费者克隆且共用请求；无工作台预热。切页／清除忽略迟到挂载，模板或视图构造失败可重试。字符集检查按钮移至标题右侧，生成文件按钮对齐；原页面业务和缓存校验规则保持。 |
| 沙盒设计 | 仅同步设计方向，不合并结果引用分支或沙盒分支，不新增执行工作区、保存中间变量函数或配置。 |

普通客户端继续使用原有 HTTP／SSE／Live／History 类型和完成方式；不新增公共事件类型。渠道媒体新增可选 `url`，旧 `file_id` 调用保持。普通工具及外层 `run_code` 的大结果保护仍在，内部调用继续受既有程序硬限制。

## 审计修复

- 诊断首次直达不再依赖工作台先注册模板，补齐 single-flight、消费者独立副本、失败重试和迟到路由守卫。
- 第二次复审用构造异常复现了未处理 Promise 拒绝：只读视图构造不在原错误处理内，页面会停在加载中。已纳入同一代次守卫，清理残缺 DOM 并提供重试；新测试先在旧逻辑失败，再确认修复。
- 畸形 IPv6 URL 在发送前转为可纠正输入错误，不能误记成已分发后的送达未知。
- 代理检测补齐系统代理来源；公共 DNS 被透明代理改成假地址时回退系统解析，返回地址仍经过原 SSRF 检查，不允许私网或假地址。

没有扩大清理计划、历史 instructions、结构化输出配置或其他真实执行事实，没有修改原 Agent、Skill、用户配置及原会话。

## 真实网络限制

公开图片的真实 Provider／正式 ASGI HTTP SSE 探针完成了失败后继续执行，但本机 DNS（包括发往公共 UDP DNS 的查询）返回 `198.18.0.0/15`、`2001:2::/48` 假地址，成功图片下载仍被安全拒绝。该成功路径记为环境阻塞，未计通过；图片成功、坏图后换图、SDK 请求体和持久化边界由隔离网络／SDK 测试覆盖。

另核实 `https://1.1.1.1/favicon.ico` 实际先返回 301，跳转到 `one.one.one.one` 后才遇到假地址；IPv4／IPv6 字面 IP 均未发生 DNS 查询，不是 IP 被错误替换。不为实测通过而放宽 SSRF、TLS 或修改本机网络设置。此版不承诺修复该网络环境。
