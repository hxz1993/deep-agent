## 原型入口

打开 [诊断中心四方案 HTML](prototype.html)。无需构建或服务，可直接在浏览器打开。
样例全部为虚构数据，不访问业务接口、日志文件或真实会话，不写入浏览器持久存储。

顶部方案按钮切换导航布局；下方内容模式可独立切换，支持混搭。每个方案均包含日志、会话排查、
会话统计三个内容页。行可选、详情可展开，关键词与 Agent 筛选使用模拟数据。

| 方案 | 导航组织 | 默认内容组合 | 适用场景 / 代价 |
| --- | --- | --- | --- |
| A · 平铺页签 | 保留诊断中心主入口，内容顶部三个页签 | 日志表格右详情 / 会话表格右轨迹 / 统计概览 | 改动小、横向空间大；功能增多时顶部拥挤 |
| B · 专属侧栏 | 主导航后增加诊断二级侧栏 | 日志上下分栏 / 会话双栏问答 / 问题明细 | 功能可扩展、定位明确；多占一栏 |
| C · 导航内展开 | 诊断中心在主导航中展开三个子入口 | 日志时间线 / 会话上下分栏 / Agent 对比 | 不加第二侧栏；主导航层级变深 |
| D · Agent 工作台 | 先选 Agent，范围内切三个入口 | 日志上下分栏 / 会话双栏问答 / 问题明细 | 适合持续运营某个 Agent；全局排查多一步范围选择 |

## 三种内容边界

- **日志**：当前实例 API / 网关安全运行日志，不含正文、参数或凭据。只读、手动刷新。
- **会话排查**：新增独立管理员接口，跨用户查看真实历史与轨迹，关联日志；普通用户接口权限不变。
- **会话统计**：汇总已有会话事实，查看不同 Agent 的用户提问与最终回复；一条真实提问一行，
  追问保留会话入口。执行完成不等于回答正确；不自动推断满意度、问题已解决或业务意图分类。

拟复用 Event Store 作为问答事实源；不把正文复制到诊断文件，不增加 RUN 回执或并行事实库。
原型中的概览、轨迹导出、统计和管理员会话入口是待确认设计，当前本地日志查询实现见
[诊断日志指南](../../guides/diagnostic-logs.md)。跨企业范围仍需后端明确授权约束，不能只放宽 user 条件。

## 可操作内容

- 4 种外壳 × 3 类内容页 × 每页 3 种内容组织，可自由组合；切页保留原型筛选。
- 关键词、Agent 与执行状态筛选；会话名称模糊 / 完整模拟 Session ID 精确查询。
- 选中日志看安全字段；选中会话看问答、轨迹、关联日志；问题明细跳转所属会话。
- 模拟无结果、权限不足、日志不可用、部分范围状态；这些状态不伪装成空列表。
- 只演示现有范围内的只读操作。无发送、停止他人会话、删除、真实下载、自动诊断或远程请求。

## 推荐组合（待确认）

首版推荐 A 的顶部页签 + B 的双栏会话排查 + B/D 的用户问题明细。
先让管理员能凭 Session ID 查现场、按 Agent 收集原始问题；统计图只做辅助，不先建设大屏。
大屏展开和窄屏查看均保留同一信息层级。

## 相关工作台需求

普通会话栏搜索采用后端分页检索：名称模糊、完整 Session ID 精确；查询范围仍限当前用户和 Agent，
不因为新增诊断能力而开放普通会话权限。此需求与管理员诊断查询是两条不同入口。
