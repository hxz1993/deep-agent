# 0.15.10 发布审计与性能回归

日期：2026-11-05。分支：`test`。开发基线：`62d1a1860b8c2eed0973b3cdd4ef2afce3b3ae29`（0.15.9）。本轮将已确认的 Console 性能、运行时目录和测试效率改动一起发布为 **0.15.10**。依赖变更：无；数据库保持 **013**；不部署线上，不改电子表格助手。

## 改动与审计结论

- 流式 text/thinking 按 75 ms 合并展示；工具、分段和终态先刷新。流式期间暂停代码高亮，完成后恢复；原始内容、净化、复制和下载规则保留。
- 隐藏轨迹保留事实但不重建 DOM；可见轨迹复用稳定行，详情按需更新。统计缓存按事件集合失效，摘要只扫描新增文本，避免逐帧重扫全文。
- 折叠工具结果延后解析；图标只处理新增子树，销毁时移除排队引用，已脱离文档的节点不再处理。
- Markdown 依赖缺失、Mermaid 加载失败、Mermaid 解析失败分别只警告一次；每个失败位置仍显示自己的错误与源码，依赖恢复后仍可重试。没有拦截全局 console。
- 正常 SSE／Live 不变。仅 History 兜底路径将整份历史读取间隔改为 3 秒，状态仍每秒检查；首次、状态变化、手动刷新、读取失败后的重试和终态立即读取。不能仅凭事件 head 跳过检查点更新；最终权威历史先完成再解锁。移除两处全文 JSON 签名，保留内容比较及迟到响应隔离。
- 运行时工具目录合并为“基础运行、文件与结果、Skill、MCP、渠道消息”五组，仅调整说明与展示，不改变工具装配、授权或 PTC。
- 消除测试类导入带来的 87 次重复收集，合并 2 项完全重复用例，新增 10 项执行入口验证；完整 Python 净减 79 项。新增 `all`／`quick`／`affected` 入口及显式领域映射，未知影响面回退全量；没有引入并行测试或共享可变数据库。
- 本轮第一次全量暴露诊断等价测试的内存 SQLite 表丢失。该用例改为独立临时文件数据库，并按 persister、engine、目录顺序清理；断言和超时不变。内存连接重建会丢库的机制已复现，原失败日志不足以证明具体的连接失效触发原因。修复后模块连续三次通过，再完整回归。
