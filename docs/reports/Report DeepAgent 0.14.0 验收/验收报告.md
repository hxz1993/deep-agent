本次在 `test` 完成结构化输出、Agent 更新人及原有 19 项工作。发布基线为 `552b7b25291e85a23b22244d5178823f1c60570e`（0.13.9 / 数据库 011）；目标为 0.14.0 / 数据库 012。最终交付提交以带说明的 `v0.14.0` Tag 指向为准，不在正文写入无法自引用的文档提交 SHA。

## 交付与行为

- Agent“输出”页签默认关闭，一份组合 JSON Schema；所有顶层可选且允许 `{}`。卡片两行回显，外部仅“必须”及删除，详情编辑与原生编辑共用定义，页头一次事务保存。
- `agent_output_configs` 一张定义表；Agent 新增非空默认 false 开关及可空可信 `updated_by`，原子记录定义、开关、时间和操作者。Username 批量解析，卡片和列表显示；普通初始化不依赖管理员专用 Schema 接口。
- 一个 ToolOutput 及真正 UI Deferred，Turn 内冻结 Schema；恢复读原事件快照，不被当前 Agent 修改/关闭/删除覆盖。完整响应分发前拒绝多输出/混调；每 Turn 两次修正与 SDK 共用，恢复不重置，最后请求仍保留输出工具。
- 独立子进程完整 JSON Schema 验证：执行/排队各 2 秒，每 Worker 两个 active、16 个等待者，超时和取消 kill/reap；容量和系统故障不要求模型纠错。Schema/定义缓存有界，不补默认值/强转。
- HTTP/SSE/Live/History/Event API 统一原生 JSON。真实调用、SDK ack、预算及必要状态持久后，才保存不可变接受事实并发成功。失败候选只在轨迹，成功/失败均“输出”标签；History item_id=output_id。关闭路径不添加新字段/事件。
- Console 通用 JSON/正文双视图、英文编码标题、超过 15 行折叠、完整复制/下载。模式偏好跨刷新保存一个枚举，不保存业务值。渠道按 UTF-8 字节上限分段确定性文本，确认失败不重发，API 保持原生 JSON。
- 原有字符集展示、首轮命名/`/new`/续聊回归、固定依赖镜像交接独立提交 `90b3d7c`；原 19 项无遗漏。
