# DeepAgent 导航宠物资产

与其他 Console logo/icon 一起存放于 `console/assets/`。正式运行不依赖 output 原型目录。

- `sprite-pet.js`：无第三方依赖的 Web Component、逐帧播放和随机待机调度。
- `final/*.webp`：12 组透明动作图集，共 92 帧；每帧 192×208，按等比 viewport 渲染。
- `prompts/`：各动作生成与修订说明，方便后续补帧；基于用户确认的原始 SVG，通过内置 imagegen 生成。

`console/main.js` 的 `setConsoleNavigationWidth` 是导航状态唯一入口，同时更新组件的 `collapsed` 属性；点击机器人、拖动边界和键盘调整都会同步。收起为无腿蹲姿，展开为站姿；露脚坐下休息是展开状态的待机动作，不改变导航。

站姿随机眨眼、张望、摆头、走两步和上下看；站久了坐下休息再站起。蹲姿随机眨眼、左右／上下看、摇头晃天线，静置后睡觉。睡眠约 9–12 秒，展开立即唤醒。动作遇后台页面、减少动态效果或 `paused` 属性会停止，移除组件时释放定时器和监听。

头部宿主尺寸为 40×44px，小屏为 38×44px；尺寸通过 CSS 调整，不能独立拉伸素材。加载期间使用同目录外的 `../../favicon.svg` 静态兜底。品牌文字及连接状态仍由现有 Console 管理。

替换图片保持帧数和原点／底部基线；新增动作需同时更新 ROWS、随机调度及动作分支。修改组件或图集时更新 main.js 导入版本和组件图片版本，避免缓存混用。不要把临时生成源图、评审截图或运行中的原型服务器作为部署依赖。
