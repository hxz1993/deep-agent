# DeepAgent 用量页第二轮图片原型

2026-09-23，按用户提供的本地应用 Usage 页参考重新生成。使用内置图片生成工具；不涉及产品实现或统计口径变更。

- A：堆叠总览，以 Agent 堆叠柱图和集成图例展示分布，下方为用途及用户前几名。
- B：纵向趋势，按模型用量、请求活动、用户用量分组，折线与堆叠图分段展示。
- C：可切换分析，突出指标、维度、图形类型切换，用一张主图集中分析。

共同规则：枚举较少的 Agent、用途可堆叠；人员、模型等数量较多时展示前几名与其他，可查看全部。图例集成名称、占比或数量，不堆砌同质卡片。不混合 Token、请求次数等不同单位。

图片内均为示例数据，文字、数字、坐标与曲线仅供视觉选型，不作为统计验收。原始完整生成提示词见 prompts.json。打开 index.html 切换查看，图片可点击放大；该文件只是图片浏览器。

沿用原产品侧边栏和管理员可见范围。旧三版保留在上级目录，便于比较。
