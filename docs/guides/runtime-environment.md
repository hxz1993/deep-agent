# 运行环境工具

`runtime:environment` 是后端只读工具领域编码，不是 Agent 可选工具包，不写入 Agent 安装包。
所有业务 Agent 通过统一构建入口获得一份 `get_current_time`，不要求关联能力；标题、压缩和 Provider 连接测试等内部辅助请求不会因此新增工具。

Console 将运行时目录展示为五组：**基础运行、文件与结果、Skill、MCP、渠道消息**。基础运行汇总时间、任务计划和会话历史；文件与结果汇总文件读取／查看／发布及完整工具结果读取。此处只做前端目录聚合，后端 `/system-tools` 仍返回原领域及各工具的实现来源、注入条件；不改变 Toolset 装配、授权、PTC 白名单或安装包引用。

## 获取当前时间

```python
get_current_time(timezone: str = "UTC") -> str
```

默认调用 `{}` 返回实际 UTC 时间，格式沿用带偏移的 ISO 8601 字符串，如 `2026-11-05T08:30:00+00:00`。
传入 `{"timezone":"Asia/Shanghai"}` 返回北京时间，如 `2026-11-05T16:30:00+08:00`；`America/New_York` 自动使用对应日期的夏令时偏移。
每次调用重新读取时钟，不缓存结果，不从语言、App、Header 或服务器 `TZ` 推断用户所在时区。

空值、非法名称或缺少对应时区数据时，工具给模型返回参数纠正提示，不静默回退。
工具说明和错误通过既有 SDK 机制处理，返回值不增加 JSON 包装；时间工具不进入 PTC，启用 PTC 的 Agent 仍可在外层调用。

## 渠道消息与说明

已验证的渠道 Run 自动加载 `channel_message` 和 `channel_doc()`。渠道类型由服务端从本轮账户取得，`channel_doc()` 只返回该渠道的说明，无需传参。它与网关 `/help` 共用快捷命令，按适配器说明群聊和私聊用法、入站内容、图片与语音限制、引用及转发支持。调用时读取当前服务端附件配置，并与适配器的媒体限额一起计算可发送大小。模型侧的结构化输出使用 `output__` 命名空间，即使输出编码也叫 `channel_doc`，两个定义仍可同时使用。

普通文字回答由渠道自动投递，主动发送图片或附件时参照 `channel_message` 的工具说明。渠道和普通会话均按 Agent 配置装配 UI 工具。调用需要浏览器交互的工具时，渠道按现有流程提示在 DeepAgent 控制台继续完成。

## 旧引用与安装兼容

`builtin:general` 已退役，统一能力编码规范化时过滤这一已知编码；其他能力及非法、重复引用的校验保持。

| 场景 | 行为 |
| --- | --- |
| 旧数据库含旧引用 | 对外读取、运行和数量统计忽略它；不批量更新数据库或历史事件 |
| 新建、编辑、复制 | 接受旧客户端传入的旧引用，保存时移除 |
| 旧包在新版预检、安装或覆盖 | 不产生缺失资源或无意义的解除关联提示，时间工具默认可用 |
| 新版导出 | 省略旧引用，也不写入 `runtime:environment`；ZIP 仍为 schema_version 1 |
| 新包在旧版安装 | 无时间包关联，按旧版规则安装；不补偿旧版的时间能力 |
| 配置备份恢复 | 使用原备份格式和规范化入口；有无旧引用均按新版运行规则执行 |

既有预制 ZIP 不必批量重打。旧会话中的 `get_current_time` 名称、返回内容与事件保持原样。

模型侧按工具来源分配名称。内置工具沿用原名，手工 UI 工具和 MCP 使用 `ui__<包>__<工具>` 与 `mcp__<服务>__<工具>`，结构化输出使用 `output__<输出编码>`。不符合供应商名称限制时使用稳定短名。同名配置可在不同类型共存，UI 工具目录仍按原有的唯一编码管理。SSE、History、轨迹及 Agent 包沿用业务名称，旧的待交互请求继续按 `tool_call_id` 恢复。PTC 脚本沿用原有函数名，函数名本身冲突时两项仍可各自通过普通工具调用。

## 部署与验收

使用 Python 标准库 `zoneinfo`，不新增 pip 依赖或部署环境变量。默认 UTC 不依赖宿主本地时区。
镜像中的 IANA 时区数据是非 UTC 时区的运行前提；构建／部署时在实际镜像执行：

```bash
python -c 'from zoneinfo import ZoneInfo; print(ZoneInfo("UTC"), ZoneInfo("Asia/Shanghai"), ZoneInfo("America/New_York"))'
```

时区数据缺失应报告环境阻塞并补齐基础镜像数据，不采用启动时安装或退回服务器时区的方案。
macOS 本地通过不能代替生产 Linux 镜像验证。数据库仍为 013，不修改依赖、安装格式或聊天协议。
