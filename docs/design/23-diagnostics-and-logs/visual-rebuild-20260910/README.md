## 视觉依据与取舍

使用用户补充的 DevBox 启动台、DeepFOS 新建中心及资源工作台图片，同时核对 DevBox `static/themes/ops.css` 与 `static/base.css`：冷灰蓝画布、白色工作区、清晰的深色文字、粉彩图标块、蓝色主操作、12px 卡片与8px控件圆角。

使用 `gpt-image-2-style-library` 的 **UI Screenshot System** 模板，再通过**内置 imagegen**生成3张主稿。提示词在 [prompts.md](prompts.md)。先锁定主稿，再用浏览器截图逐项校准，未用图片作为生产页面背景。

初轮 L4/S1/S2 和 HTML 原型保留信息组织与查询逻辑依据；本轮明确允许这两个新查询页独立采用 DevBox 视觉，不再强制复制配置目录的小字号。只读会话详情不受这套视觉变量影响。
